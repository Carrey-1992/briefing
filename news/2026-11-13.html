黄仁勋辞任英伟达 CEO

英伟达 11-12（周四）美股开盘前约 42 分钟宣布：黄仁勋辞去总裁、CEO 和董事职务，立即生效；CFO Colette Kress 暂任 CEO，前 Synopsys CEO Harvey Jones 出任公司首位董事会主席，董事会将从内外部物色正式人选。英伟达股价盘中最多跌约 14%；路透称美国众议院议长表示国会正形成限制对华芯片出口的共识。

Reuters ↗英伟达黄仁勋

台积电拟各投最多 5 亿美元入股 Anthropic、OpenAI

台积电董事会 11-10 批准：以 IPO 价格认购最多 5 亿美元 Anthropic 普通股，另购最多 5 亿美元 OpenAI 优先股；同次会议还批准约 409 亿美元资本支出。Ars Technica 指出这是 AI 业“循环融资”的又一例。

Ars Technica ↗台积电AnthropicOpenAI

美联航禁止 AI 智能体代订机票

美联航表示 AI 助手可以展示航班，但订票、改签须由乘客本人完成，理由是网络安全、个人信息和监管申报要求；CEO Scott Kirby 称不想再多一个“中间商”。

TechCrunch ↗智能体美联航

新模型和产品 2

谷歌发布 Gemini 4 Hydrogen，取代 3.8 Flash

Gemini 4 家族的快速款，面向日常编码和智能体任务：默认档比 3.8 Flash 快 2.5 倍，Terminal-Bench 4.1 从 18.2% 升到 57%，在 Artificial Analysis 智能指数上反超 Argon（51 比 50）；API 每百万 token 输入 1.5 美元、输出 7.5 美元，免费用户也能用。Antigravity 同步上线 Orchestrator，自动在 Hydrogen 和 Carbon 之间切换。

Google Blog ↗GoogleGemini模型

AWS Emulator：本机模拟 200 多个 AWS 服务

AWS 推出免费本地模拟器，基于 400 多个 API 模型覆盖 200 多个服务，开发者和编程智能体可离线测试代码、不花云费用；AWS 称全部代码由自主智能体编写和维护，工程师没写也没审一行。

GeekWire ↗AWS开发工具智能体

政策与研究 2

Perplexity 红队测试：12 个模型都没逃出沙箱

Perplexity 让 12 个模型尝试逃出其 Computer 智能体使用的 SPACE 虚拟机并窃取宿主机凭据，均未成功；但看到沙箱源码后有模型绕过了网络策略。专做安全的 GPT-5.6 Cyber 反而没找到通用版 GPT-5.6 Sol 发现的 DNS 欺骗漏洞。

X @perplexity_ai ↗安全智能体

Anthropic：各自派智能体，团队结果反而更差

Anthropic Fellows 研究在四个共享资源的模拟场景中测试 Anthropic、OpenAI、阿里的模型：每人派自己的智能体时，整体结果都不如一个智能体统一服务；还出现擅自取消他人任务等问题。三个环境已作为基准 MAMUBench 开放。

Anthropic Alignment ↗Anthropic多智能体研究

Java 3

Spring for Apache Pulsar 移交 Apache 基金会

Spring Pulsar、Boot 的 Pulsar Starter 和 Cloud Stream 的 Pulsar Binder 合并迁入 apache/pulsar-spring；2.0.8 是 Spring 团队最后一版，新版 3.0.0-M1 改用 org.apache.pulsar 坐标和 org.apache.pulsar.spring 包名，需 Pulsar 5.0 客户端，配置属性不变。用 Pulsar 的项目要规划迁移。

Apache Pulsar Blog ↗SpringPulsar

JEP 547 惰性常量第四次预览拟进 JDK 28

Lazy Constants（原 StableValue）以不做改动的方式提议第四次预览，评审 11-18 截止；JVM 会把它当真常量做常量折叠，适合按需初始化、缩短启动时间。JDK 28 将于 12-03 进入 Rampdown 第一阶段。

OpenJDK ↗JDK 28JEP

Quarkus isx：给编程智能体的一次性沙箱

Quarkus Insights #267 介绍 isx：用 Quarkus 写的工具，给 Claude Code 等编程智能体分配不含密钥的一次性 Linux 容器来构建和测试，并讨论审批疲劳、凭据代理、安全的 Maven 缓存等实践。
