Anthropic 招股书草案曝光

据《华尔街日报》看到的 S-1 草案，上半年营收 163 亿美元，净亏 807 亿美元，其中约 720 亿是可转债估值变动的非现金费用；上半年算力和基础设施支出近 90 亿美元，IPO 预计在 11 月。

IBM CEO：企业开始怀疑 AI 投入回报

新模型和产品 4

OpenAI Decisions API 正式可用

由 gpt-6-luna 驱动，专做分类、路由、打分这类快速判断，比 Responses API 快最多 10 倍，单次请求最多 400 个问题。Java 侧 LangChain4j 1.22 已有 OpenAiDecisionModel 支持。

OpenAI ↗OpenAIAPI

谷歌推出 Gemini API CLI 和 Agent Compute Engine

一个命令行二进制就能让智能体调用图像、视频、语音、音乐生成；Agent Compute Engine 用隔离 microVM 跑大规模智能体，两者均为预览版。

Ideogram 发布首个矢量模型

文字或图片直接生成分层、可编辑的 SVG，可导入 Figma、Illustrator，平台和 API 已上线。

Hugging Face 开源 DNA 对话模型 Carbon-X

政策 2

美财政部发布 COINS 法案实施细则草案

把对外投资审查扩大到中国、俄罗斯、伊朗等多国，涉及 AI、半导体、量子、超算、高超音速和生物技术，部分投资需申报、部分直接禁止，意见征集到 12 月 7 日。

《华盛顿邮报》-ABC-Ipsos 调查 2545 名成年人，三分之二反对新建数据中心并希望加强联邦监管。
