大公司动态 3

微软收缩 neocloud 伙伴，据报不续约甲骨文 AI 算力

知情人士称微软正在评估并缩减 neocloud 合作名单，优先自建机房；已选择不续约 2023 年与甲骨文的 AI 算力租用（旧代 Nvidia 芯片已不匹配需求），近月持续关停租用容量。微软称会按客户需求定期复盘基建合作；甲骨文称 OCI AI 需求仍强。（CNBC，11-06；Bloomberg/Reuters）

CNBC ↗微软甲骨文AI 基建

英伟达收紧东南亚云伙伴芯片追踪，防走私至中国

Bloomberg 报道：东南亚申请 Nvidia Cloud Partner（NCP）须接入 Fleet Intelligence，监控 GPU 库存、遥测与地理位置等；更广追踪计划仍多为自愿。背景是美国加强对经东南亚转口受限 AI 芯片至中国的调查。（TechRepublic 转述，11-06）

TechRepublic ↗英伟达出口管制东南亚

Meta 无限期推迟有争议商业条款更新

原拟要求 Meta 商业账号允许对其页面外链站点进行广泛抓取并用于产品开发（外界担忧可绕开 robots.txt 训练 AI）；遭出版商、英美监管与巴西/挪威禁令后，Meta 宣布无限期暂停，现有条款继续有效，称将继续磋商。（Ars Technica，11-06；The Verge）

Ars Technica ↗Meta版权AI 训练

新模型和产品 3

OpenAI 发布 BioBasicsBench：测 AI 读湿实验原始数据

与酶设计公司 Ligo 合作，100 项日常湿实验任务（凝胶、显微、测序读数等）；GPT-6 Astra 在 xhigh 推理设置下均分 66.7%，GPT-5.6 Sol 为 43.8%。强调真实实验歧义与对照组判断，而非精选论文图。（OpenAI 官方，11-06）

OpenAI ↗OpenAI生物基准

Meta Muse 上线实时语音与表情头像

美国用户可在 Muse（移动/网页/Mac）用实时语音与 Muse 对话；头像随对话做表情与手势，可纯语音、并排或全屏。基于 Muse Realtime Voice/Avatar，后续还将上 AI 眼镜与 Muse Charm。（Meta 官方，11-05/06）

Meta ↗MetaMuse多模态

百度开源文心 ERNIE 5.5 Flash Base（280B MoE）

预训练终点 Base 权重开放（未经中训/后训），总参 280B、每 token 激活 14B，训练 33.5T tokens；最长训练上下文 128K，微调/推理支持 1M。混合稀疏注意力 + Multi-Router Latent MoE，Hugging Face 提供 FP8/BF16，定位领域适配与 Agent 训练起点。（百度文心，11-05）

百度文心 ↗百度开源模型MoE

政策与研究 3

METR：Anthropic 能力进步约加速至历史约 2 倍

METR 在 Anthropic 高权限评估（8-12 至 10-29）后公开报告：按 AECI，自 2025-10 起基准进步约 1.9×（95% CI 1.5–2.8×）；多数加速归因于 AI 辅助 R&D（约 80% 主观估计，不确定性大）；未看到未来 12 个月明显瓶颈，但大量证据被 Anthropic 以保密为由涂黑。（METR，11-05）

METR ↗AnthropicAI 安全研发加速

Frontier Model Forum 发布网络越狱评级框架 v1.0

FMF（含 AWS、Anthropic、Google、Microsoft、OpenAI 等）发布对成功 cyber jailbreak 的比较风险评级：按能力增益、范围、部署难度、发现难度四维合成 Negligible→Critical；公开征求意见至 2026-12-21。（Frontier Model Forum，11-05）

Frontier Model Forum ↗AI 安全越狱行业标准

Visa：AI 购物代理约半数跑不通

Visa Agentic Commerce Benchmark 覆盖 22 个模型、12 家实验室、15 类真实购物场景；总通过率约 57.2%（最好 82.2%、最差 28.9%）；失败 run 中约 54% 仍完成了错误购买。Visa 称将扩展至结账与支付。（Visa，11-05）

Visa ↗Agent电商评测

Quarkus×LangChain4j：组合式 Agentic PR Reviewer，成本不到 1 美元

Mario Fusco 详解用 Quarkus LangChain4j（1.15 / LangChain4j 1.21）把路由、辩论、投票、反思循环与人机确认组合成 PR 评审系统；对约 2900 行 PR 评审约 0.45 美元；决策模型做评审员路由，非 AI agent 做校验与校准。（Quarkus Blog，11-04）

Quarkus ↗QuarkusLangChain4jAgent

JetBrains《Java Annotated Monthly – November 2026》发布

月度精选上线，聚焦 JDK/JEP（含 Java 28 与值对象预览等）、教程、Kotlin、AI 工作流与生态动态，适合作本周 Java 纵览入口。（JetBrains Blog，11-06）
