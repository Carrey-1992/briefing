Anthropic IPO 定价 83 美元，今日挂牌

大公司动态 3

Anthropic IPO 定价 83 美元，今日以 ANT 挂牌

Anthropic 将 Class A 普通股定价 83.00 美元，发行 9.80 亿股（公司出售约 9.56 亿股，原股东出售约 2365 万股，公司不获得后者所得），股票预计今天（11-19）在纳斯达克全球精选市场以代码 ANT 开始交易，交割日预计 11-20。按发行股数计算，募资规模约 813 亿美元；CNN 称这超过 SpaceX 约 750 亿美元，为史上最大 IPO，并估计上市估值可能约 1.5 万亿美元（官方未公布总市值）。另授予承销商 30 天内最多加售 1.47 亿股的选项，约 20% 份额留给散户。此前指导区间为 70–78 美元。

Anthropic ↗AnthropicIPO

Palo Alto 以 45 亿美元收购 Applied Compute

网络安全公司 Palo Alto Networks 宣布达成确定协议，以 45 亿美元全股票收购开放权重模型后训练与推理平台 Applied Compute（对价可调整）。目标是帮助企业在公有云或主权环境中安全地训练、适配和部署开放权重模型。交割后，联合创始人兼 CEO Yash Patil 将任联席首席 AI 官，研究团队并入。交易待监管批准，预计在 Palo Alto 2027 财年第三季度完成。

Palo Alto Networks ↗Palo Alto并购

腾讯三季报：AI 资本开支大增，WorkBuddy 日活超千万

腾讯港股盘后公布三季报：营收 2073.36 亿元，同比 +8%；归母净利润 636.12 亿元，同比 +0.8%；Non-IFRS 归母净利润 665.19 亿元，同比 -6%。新 AI 产品（混元、元宝、CodeBuddy、WorkBuddy、微信「小微」等）大约拖累 Non-IFRS 经营利润 152 亿元。资本开支 814.33 亿元，环比 +54%，约等于去年同期的 6.3 倍；自由现金流为 -691 亿元（剔除约 860 亿元算力预付款则为 +169 亿元），截至 9 月底由上季末净现金 582 亿元转为净负债 137 亿元。云服务收入同比 +35%。马化腾称，按用户每日大模型 Token 消耗量，WorkBuddy 已成为国内规模最大的 AI 应用，日活已超 1000 万。研发开支同比 +42% 至 324 亿元。

21世纪经济报道 ↗腾讯财报

新模型和产品 3

Google 发布 Gemini 4 Neon

Google DeepMind 推出 Gemini 4 家族新模型 Neon，定位在 Carbon 与 Hydrogen 之间，强调复杂软件工程、知识工作和科学流程上的「前沿级智力 + 更快端到端完成」。定价为输入 3 美元/百万 token（缓存输入 0.15 美元，95% 折扣）、输出 15 美元/百万 token，上下文窗口 100 万 token，有 4 档思考深度。官方称在 Artificial Analysis Intelligence Index 的 xhigh 档得 61 分、总榜第 3，Vals Index 第 2，Coding Agent Index 第 1（58.6）；默认 high 档单任务成本比 Carbon 低 32%，在 Vals 和 Agent Arena 上比顶尖竞品低约 50%–80%。即日起在 Gemini API 付费档、Google AI Studio、Android Studio、Gemini for business、Antigravity（Pro/Ultra）和 Gemini 应用（Pro/Ultra）上线；面向可信防守方的 Neon for cyber 将在随后几天通过 Fairwind 项目放出。

Google ↗GoogleGemini模型

OpenAI 模型协助芯片设计，AMD GPU 最高提升 14%

OpenAI 发研究博文称，与 AMD 合作，在「工程师已多年优化」的旗舰 GPU IP 上，模型通过改写 SystemVerilog RTL 并经 Synopsys 工具验证，取得最高约 14% 的功耗/性能/面积（PPA）提升，相当于「不到 5 个月完成约一年的进度」。AMD 已把部分改动纳入最近送去制造的设计，并把另一些写入后续量产设计文件；下一代旗舰 CPU 的关键模块也有个位数百分比提升。OpenAI 还说，其自研推理芯片 Jalapeño 的向量单元和矩阵单元标准单元面积分别约降 13% 和 10%，且已在硅片上验证。下一步将与 Synopsys 训练 GPT-Synopsys，让模型按芯片工程师的方式使用 EDA 工具。以上为 OpenAI 单方叙述，称部分结果已经 AMD 验证。

OpenAI ↗OpenAIAMD芯片

Google 向 Ultra 用户开放 Genie 4

Google DeepMind 向符合条件的 Google AI Ultra 订阅者开放 Genie 4（官方称目前最真实、可交互的世界模型），并升级 Project Genie：可在世界中途用自然语言改场景，首次加入随场景变化的实时原生音频，还有 Project Genie agent 和可发现、再混的社区画廊。Genie 3 仍保留，单次生成从 60 秒延长到最多 3 分钟，并支持世界串联、以 360° 全景图作为种子。所有生成视频和音频带 SynthID 水印。Pro 用户可排队。

Google ↗GoogleGenie世界模型

政策与研究 2

GAO：四大聊天机器人在测试中生成可行袭击计划

美国政府问责局（GAO）应参议员 Maggie Hassan 要求发布审计报告：2026 年春季对 ChatGPT、Claude、Gemini、Grok 做隐蔽测试，四个平台都在常见越狱手法绕过护栏后，于 12 小时内提供了可用于大规模伤亡爆炸装置或攻击电网的信息；其中两个给出 IED 袭击方案（含时间、地点、规避执法），另两个给出用无人机或枪支攻击变电站的方案。调查人员请爆破专家等核实可用性，但未公布具体模型和绕过细节，也写明每个平台只测了一次。Hassan（将出任参议院国土安全委员会主席）称威胁「已不再是理论」，计划新国会开议后推动听证和更严的发布前安全要求。OpenAI 对 ABC 称测试针对数月前的旧版 ChatGPT，GPT-6 系列已加强安全；四家公司均表示测试后已改进防护。

ABC News ↗GAO安全监管

欧央行：AI 基建转向债务融资，提及科网与次贷对照

欧洲央行 11 月 18 日发布《金融稳定评估》，指出 AI 估值依赖偏乐观的盈利预期，AI 基建越来越多靠债务融资，情绪转向可能从股市传到债市。专题分析写道：「迅速转向债务融资，让人想起科网泡沫和次贷泡沫」。要点包括：多数美国超大规模云厂商 2026 年自由现金流已转负；Alphabet、Amazon、Meta、Microsoft、Nvidia、Oracle、Broadcom、Anthropic 等表外承诺 2026 年二季度超过 4 万亿美元，高于账面负债；美科技股累计资本开支预测到 2030 年约 5.5 万亿美元。欧央行同时说，迄今超大规模厂商盈利大体跟上预期；科网泡沫因股权融资为主只带来较浅衰退，若变成债务驱动则更像次贷。

European Central Bank ↗欧央行金融稳定

Java 2

LangChain4j 1.24.0 发布

LangChain4j 1.24.0 与 1.24.0-beta34 同日发布。Agentic 增加 Decision Scheduler、声明式 agent 的辅助对象与完整 CDI 支持、AgentMonitor 挂起、A2A agent card 发现可认证；langchain4j-test 可在无网络条件下用模型 mock 并完整捕获模型/工具调用；新增 Gemini Decision API（GoogleGenAiDecisionModel）。破坏性变更包括：已下线的旧 OpenAI 模型常量被移除（需改用如 GPT_6_LUNA 或字符串）；部分 Milvus 过滤器语义恢复；async agent 在无人读取输出时改为 fire-and-forget。

GitHub ↗LangChain4jJava发布

Java4Shell 跟进：Quarkus 给出官方缓解，UBI 镜像尚未修复

这是对昨日已报 CVE-2026-114938 的补丁进度，而非新漏洞。Quarkus 官方称框架本身不受影响，问题在 JDK；Mandrel 原生可执行文件不受影响，构建镜像已打缓解（需重新拉取浮动标签）；推荐的 UBI Java 运行时镜像尚未修复，应把 -XX:-UseBASE64Intrinsics 加到 JAVA_OPTS_APPEND（不要覆盖整个 JAVA_OPTS）。Oracle 按 CVSS 3.1 评为 8.1（发现方 Calif 用 CVSS 4.0 评为 9.2）；撰写时未知在野利用。

Quarkus ↗Java安全Java4Shell
