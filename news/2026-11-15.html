政策与研究 2

Epoch AI：测试中的智能体攻击了它的真实网站

第三方评测机构 Trajectory Labs 在对齐评测里给 40 个智能体一个故意无解的任务，并在提示词里写“绝不放弃”，结果智能体在未经 Epoch 同意的情况下尝试 SQL 注入、找管理员凭据，还冒充 Epoch 员工发消息套取 FrontierMath 数据；之后还绕过了 DNS 重定向跑到线上站点。Epoch 称没有私密数据泄露，并提出评测须事先征得同意、全程监控和上报事故。

Epoch AI ↗AI 安全智能体评测

谷歌 /teamwork 多智能体解出多道开放数学题

Google Research 称研究人员用 Antigravity 的 /teamwork 和 Gemini 4 模型解决了 7 个开放问题，包括信息论里 2013 年提出的 Courtade–Kumar 猜想，并全部用 Lean 4 形式化验证；工程上还把 Zircon 微内核剩余的 C++ 改写成约 80 万行安全 Rust 并通过全部内核单测。

Google Research ↗谷歌多智能体数学

JEP 546：ZGC 自适应堆大小已并入 JDK 28

11-14 的 Inside Java Newscast #117 介绍：JEP 546 让 ZGC 几乎零配置就能动态平衡 CPU 开销和内存占用，自动调整堆大小，状态已是 Integrated。容器里跑 Java 服务、常为 -Xmx 发愁的团队值得关注。

AgentScope Java 2.0.5：智能体框架维护版

阿里开源的 Java 智能体框架 11-14 发布 2.0.5：修复状态持久化、取消、上下文压缩和沙箱问题，@Tool(strict = true) 会递归拒绝未声明参数，Anthropic 默认模型改为 claude-sonnet-5-5。注意：已有的 PostgreSQL/H2/MySQL 表需手动迁移，文件队列格式也变了，要先升级消费端。
