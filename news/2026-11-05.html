OpenAI 和 Meta 同日收购开发工具公司（Pierre、Conductor）

大公司动态 3

OpenAI 收购 Pierre，把 Git 工具并入 Codex

OpenAI 宣布收购做 Code Storage（用 Git 存代码和历史的托管服务）的 Pierre Computer Company，Codex 里看文件和 diff 用的 Trees、Diffs 库就出自这家；Pierre 的开源项目继续开源，Code Storage 功能将并入 Codex，交易仍待监管批准。Axios 称此举直指微软 GitHub。（OpenAI 官方，11-04；Axios）

OpenAI ↗OpenAI并购Codex

Meta 收购多智能体编程工具 Conductor

Conductor 让开发者在隔离的代码副本里同时跑多个 Claude Code、Codex 等编程智能体再合并结果，用户超 10 万；团队并入 Meta 超级智能实验室，金额未披露。Conductor Cloud 11-13 只读、11-20 关闭并删除云端数据，本地 Mac 版用到 2027 年初。（TechCrunch，北京时间 11-05 凌晨；SiliconANGLE）

TechCrunch ↗Meta并购编程智能体

AMD 三季度营收 133.8 亿美元，数据中心近翻倍

AMD 三季度营收 133.8 亿美元、同比增 45%，高于预期的 130.9 亿；数据中心业务同比增 97%，四季度指引约 170 亿美元，盘后股价一度涨约 8%，缓解了市场对 AI 投资过热的担忧。（CNBC，北京时间 11-04 清晨；AMD 财报）

CNBC ↗AMD财报芯片

新模型和产品 2

腾讯发布混元 Hy4，首次支持视觉和电脑操作

Hy4 为 7700 亿参数（激活 490 亿）MoE、100 万 token 上下文，首次加入图像理解和命令行/图形界面操作能力，专门训练过 Blender、CAD 等专业软件；价格维持每百万输入约 0.9 美元、输出 2.7 美元，权重和系统卡将在几天内开放，已上线腾讯云 TokenHub、WorkBuddy、CodeBuddy、元宝和 OpenRouter。（腾讯官方，11-04；SCMP）

Tencent ↗腾讯混元开放权重

月之暗面开放 Kimi K3.1 Pro 权重

Kimi K3.1 Pro 是 2.8 万亿参数（激活 1040 亿）的多模态 MoE，100 万 token 上下文，在 24 个全注意力层上加入稀疏注意力（DSA），长上下文解码每层读取量约为原来的四分之一；vLLM 首日支持英伟达、AMD、谷歌 TPU 和平头哥芯片。（vLLM 博客，11-04）

vLLM Blog ↗Kimi开放权重稀疏注意力

政策与研究 3

发改委：加快推进人工智能综合立法

国家发改委创新和高技术发展司副司长王若萌在 11-03 发布会上表示，将加快 AI 基础性、综合性立法，并扩大对核心要素和关键应用的规则覆盖，搭建 AI 法律监管体系。（财新，11-04 12:20）

Caixin Global ↗中国AI 立法

美国中期选举：至少 38 地投票限制数据中心

据《华盛顿邮报》统计，美国至少 38 个辖区的选民在 11-03 投票通过了禁止或限制数据中心的措施，被视为 AI 行业扩张的一次重大挫折，算力基建的地方阻力正在变成选票。（Washington Post，北京时间 11-05 凌晨）

Washington Post ↗数据中心美国选举

Claude 发现 Xen 虚拟机逃逸高危漏洞

Xen 安全公告 XSA-523 修复了 grant-copy 中的两个漏洞（CVE-2026-102703/102704），恶意虚拟机可读写其他虚拟机乃至 dom0 的内存，Xen 4.6 起所有版本受影响、潜伏 11 年；公告将发现者记为 Anthropic 的 Claude，CodeAnt AI 团队也独立发现并做出了逃逸演示。（Qubes OS 公告，11-03；CodeAnt 分析）

Qubes OS ↗安全ClaudeXen

Java 2

Quarkus 4.0.0.Beta3 发布，CR1 推迟

原计划 11-04 的 4.0 Core CR1 改发了 Beta3：升级 Hibernate ORM 8.0.0.Beta4、Vert.x 5.2.3/Netty 4.2.20，最低 GraalVM 提到 25.0.4，更多扩展去掉字节码 recorder，Redis 客户端支持 Valkey URI，还修了 OTLP 导出器重复发送和卡死问题。正式版仍计划 11-25 随平台发布。（GitHub，北京时间 11-05 02:40；发布计划）

GitHub ↗Quarkus发布

Project Detroit：用 FFM API 在 Java 里跑 V8 和 CPython

Maurizio Cimadamore 在 Devoxx Belgium 介绍实验项目 Detroit：不在 JVM 上重写 JavaScript/Python，而是通过外部函数与内存 API 直接嵌入原生 V8 和 CPython，并提供 javax.script 实现，重点解决跨运行时 GC 和虚拟线程 pinning 问题；对想在 Java 里直接调 Python AI 生态的场景值得关注。（Inside Java，11-04）
