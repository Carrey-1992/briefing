DeepSeek 开源主动式编程超级智能体原型

DeepSeek 以 MIT 协议开源 dsh-superagent-prototype：一个 Router 监听 GitHub 事件和飞书消息，把任务分给并行的 Worker，结果多以 PR 交付，人在网页面板审批。测试中 95% 分位耗时 15.7 分钟（单会话 29.5 分钟）；官方定位是研究原型，Worker 权限较大，别直接上生产。（GitHub，11-01）

Java 2

读被截断的内存映射文件可致 JVM 崩溃

ClassGraph 作者 Luke Hutchison 在 jdk-dev 提交三份崩溃报告：aarch64 上 C2 编译后超过 80 字节的批量拷贝（MappedByteBuffer.get、MemorySegment.copy 等）读到被截断的映射文件会直接 SIGBUS 崩溃，JDK 17/25/26 都中；另有 InternalError 在 try 块外才抛出、x86-64 上装箱读取触发 SIGSEGV。临时规避：每次最多拷 64 字节或用 getLong 循环。（jdk-dev，10-31）

Quarkus 推出 Almanac，任选两个版本比差异

Quarkus Almanac 能对比任意两个 Quarkus 版本的配置项、BOM 依赖、扩展和公开 API 变化，覆盖从 0.0.1 到最新的全部版本；4.0 已删掉 QuarkusUnitTest 等旧 API，升级前先查一遍很省事。（Quarkus 博客，10-29）
