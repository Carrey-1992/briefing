大公司动态 2

微软全球大宕机约 18 小时

始于周四（美国时间）的 Outlook、Teams 故障一路扩散成全球云服务中断，Microsoft 365 邮件与文件、Copilot、Defender、Intune 后台都受影响；Kentik 称约 18 小时后流量才开始恢复。微软称原因是“大量服务器意外不可用”，与网络攻击或 AI 智能体无关，具体根因仍在调查。

TechCrunch ↗微软云服务故障

研究称中国顶尖开源模型用禁运 Blackwell 训练

前 OpenAI 研究员 Will DePue 分析 DeepSeek、月之暗面、MiniMax、蚂蚁的开源权重，称 Kimi K3 系列、DeepSeek V4 等带有 Blackwell 芯片训练的“指纹”。在黄仁勋离任、国会调查对华芯片销售之际，英伟达的出口管制责任风险进一步升温。

TechCrunch ↗英伟达出口管制中国

新模型和产品 3

ChatGPT Wallet：智能体替你下单付款

OpenAI 11-14 凌晨（北京时间）推出 ChatGPT Wallet，智能体“dot”可帮你挑选并完成购买；结账前要核对商品、金额和卡片，并用 Face ID 或指纹确认，商家拿到的是支付令牌而非卡号。首批只开放给部分美国 Pro 用户。

TechCrunch ↗OpenAI智能体支付

Claude Managed Agents 可自托管

Anthropic 11-12 开放自托管版私测：企业在自己的云或机房运行智能体服务端、PostgreSQL 会话库和执行沙箱，凭据由沙箱外代理注入，模型请求可走 Anthropic、Bedrock、Google 或 Microsoft Foundry；每一步操作都可通过 OpenTelemetry 导出审计。

Help Net Security ↗Anthropic智能体企业

Cloudflare 开源智能体浏览器 Kitesurf

跑在 Workers 上、不需要浏览器容器的无状态浏览器以 Apache 2.0 开源：Rust 编译成 WebAssembly，支持 CDP，可直接用 Puppeteer 或智能体框架连接，可本地运行或部署到自己的 Cloudflare 账号（需 Workers 付费版）。

Cloudflare Blog ↗Cloudflare开源智能体

政策与研究 3

四家非营利组织起诉五大 AI 公司，要求冻结前沿训练

Public Citizen 等四家组织 11-12（美国时间）在旧金山高等法院起诉 OpenAI、Anthropic、Google、Meta 和 SpaceX 的 AI 部门，依据加州不正当竞争法，请求紧急禁令暂停比现有更强模型的训练和部署，理由引用了各公司自己对极端风险的警告。

Al Jazeera ↗诉讼AI 安全

Fireworks AI 被入侵，Notion AI 聊天记录外泄

攻击者经 Fireworks 的云服务商进入其开发系统，拿走部分客户账单信息和数据集；Notion 确认约 1% 客户受影响，使用 Insights 功能的 Notion AI 聊天记录被盗，其中夹带的 API 密钥已吊销。用第三方推理平台时要注意别在对话里贴密钥。

TechCrunch ↗安全数据泄露

约四分之一第三方模型接口“缩水”

Artificial Analysis 发布端点准确度指数 v1.1，用工具调用、推理、长上下文三项测试对比 100 多个托管开源模型接口和官方权重的参考部署，约 1/4 得分低于参考，原因可能是量化、自定义内核或推理参数改动。选供应商不能只看模型名和价格。

Hermes AI ↗评测推理服务

Java 3

Quarkus 4.0.0.CR1 发布

Quarkus 4 首个候选版 11-12 凌晨发布（此前因问题从 11-04 推迟）：新增优雅停机 API、quarkus dev --remote、用 SmallRye Config 支持 Spring 的 @ConfigurationProperties，Hibernate Validator 升至 9.2.0.Beta1，并继续去掉各扩展的字节码 recorder。Quarkus 4 以 Java 21 为基线，此前计划 11 月底正式发布，现在可以开始做迁移测试。

GitHub Release ↗Quarkus

Quarkus LangChain4j 1.15.1 / 2.0.0.Beta4

11-12 同日发布：@Tool 方法支持 Optional 和递归参数类型，AI 服务返回结果保留模型响应元数据，Vertex AI Gemini 支持 Model Armor，补充 MCP 2026-07-28 协议测试，仓库新增 AGENTS.md 和给编程智能体用的 Quarkus skills；2.0.0.Beta4 已跟上 Quarkus 4.0.0.CR1。

GitHub Releases ↗QuarkusLangChain4j

Micronaut LangChain4j 2.4.0

11-11 发布：结构化输出改用 Micronaut JSON Schema 生成，AI 服务和工具不再需要 @AllowsReflection，可把 MCP 客户端工具接入 AI 服务，新增模型监听器与 Micrometer 指标、AI 服务事件；ai4jvm 汇总称还加入了监督者智能体、Google Gen AI、Milvus/Weaviate 存储和原生镜像支持。

GitHub Release ↗MicronautLangChain4j
