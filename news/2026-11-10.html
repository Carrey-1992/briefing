Anthropic 发布 Claude Fable 5.2 / Mythos 5.2

大公司动态 3

英伟达股价因黄仁勋调查走低

董事会宣布调查后，英伟达周一盘前一度下跌约 4.4%，Axios 估算对应约 1990 亿美元市值；截至上周五股价已较首批报道时累计跌约 13%。分析师预计会引发多项国会质询。

Axios ↗英伟达黄仁勋

Anthropic 34 亿美元买燃气发电机

据报道 Anthropic 接手 OnePWR Solutions 已有的燃气发电机订单，约 34 亿美元、合计 1.7 吉瓦，用于给自家 AI 数据中心供电，绕开设备长期排队。

TechCrunch ↗Anthropic能源数据中心

谷歌新增 TPU 8tx 与 TPU 8i Max

谷歌第八代 TPU 再加两款：8tx 面向机密推理，处理中数据和模型权重保持加密；8i Max 把两颗 8i 封装在一起，算力、SRAM 和 HBM 带宽翻倍，主攻超长上下文推理。

Google Blog ↗GoogleTPU芯片

新模型和产品 2

Anthropic 发布 Claude Fable 5.2 / Mythos 5.2

两者是同一底层模型：Fable 5.2 面向所有付费用户和各大云平台开放，Mythos 5.2 仅限通过网络安全或生命科学验证的机构。输出比 5.1 快最多 30%，价格降到每百万 token 输入 8 美元、输出 40 美元，1M 上下文，另有最高 2.5 倍速的快速模式。

Anthropic ↗AnthropicClaude模型

Meta 发布轻量智能体模型 Muse Ember

Meta 最小最省的模型，专做工具调用、路由、抽取、长文档解析等智能体重复活。Artificial Analysis 智能指数得分 36，与 Claude Haiku 5.5 持平，每任务成本约 14 美分，Haiku 约 41 美分。

VentureBeat ↗MetaMuse模型

政策与研究 2

Claude Code 设置文件在 GitHub 泄露密钥

Apiiro 发现，选「不再询问」后命令会原样写进 .claude/settings.local.json，超过 10 万个这类文件被传到公开仓库，约 1100 个含密码、API 令牌等，其中 215 个 gitleaks 和 TruffleHog 都没扫出来。建议把该文件加进项目 .gitignore 并轮换泄露的凭据。

Ars Technica ↗Claude Code安全

特朗普松口：不介意 AI 护栏

特朗普在 CBS《60 分钟》称愿与民主党合作制定 AI 保障措施，但不能让美国落到中国之后的「远远第二」，并未提出具体框架。此前民主党在中期选举拿下两院。

CFO Dive ↗美国监管

Java 3

Quarkus 3.33.4.2 LTS 紧急安全更新

11-09 发布，修复管理接口授权绕过（Vert.x HTTP）、Jackson Databind 多态类型校验绕过、Brotli4J 堆越界写可致远程代码执行等 CVE。用 3.33 LTS 的建议尽快升级。

Quarkus Blog ↗Quarkus安全

TornadoVM 8.1 与 TornadoInsight 的 AI 内核转换

InfoQ 11-09 周报：TornadoVM 8.1.0 可在不拷贝的情况下直接读写其他库分配的设备内存；IntelliJ 插件 TornadoInsight 2.1.0 新增实验性的 AI 辅助，把 Java 方法转成 TornadoVM GPU 内核。

InfoQ ↗TornadoVMGPUJVM

EclipseStore 4.3 重构 JVector 向量索引；Gradle 9.9 发布

同期周报：EclipseStore 4.3.0 重构基于 JVector 的 VectorIndex，支持大索引、并发加载和崩溃安全；Gradle 9.9.0 支持 Kotlin DSL 脚本增量编译。

InfoQ ↗EclipseStore向量Gradle
