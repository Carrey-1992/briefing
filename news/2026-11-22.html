亚马逊：AI 智能体 11 分钟内发现并利用零日漏洞

亚马逊把一次几乎无需人工逐步指挥的真实攻击完整公开了：操作员只给出“拿到 shell”的目标，Cairn 智能体就在约 11 分钟内发现并利用了医学影像开源软件 MONAI Label 的零日路径遍历，随后拿到 root。对加固目标它也曾连续尝试约 16 小时。维护方虽已合并修复并发布安全公告，但带补丁的发行版还没出来。这说明自主智能体用于进攻已不只是实验室演示，防御窗口正在被压缩到分钟级。

亚马逊接近 75 亿美元收购 Decart

《金融时报》周六报道，亚马逊正就以约 75 亿美元收购 AI 公司 Decart 进行高级谈判，交易最早可能于下周宣布。Seeking Alpha 援引该报道称 Decart 总部位于旧金山、成立于 2023 年；以色列《环球报》称其由以色列工程师创办，做的是提升模型推理效率的优化技术，与亚马逊自研芯片 Trainium 相关，创始人据称已同意留任五年。这是谈判进展，不是已经签约。

Cursor 考虑停用中国开源权重模型

CNBC 周五援引美国众议院国土安全委员会与对华特别委员会的调查报告称，已被 SpaceX 收购的编程平台 Cursor 告知委员会，将因地缘政治风险考虑逐步停用中国开发的开源权重模型。报道称 Cursor 的 Composer 2 建立在月之暗面 Kimi K2.5 之上；SpaceX 于今年 8 月完成收购。报告还建议在联邦信息系统和联邦合同中禁止使用这类模型。Cursor 和 SpaceX 未回应置评请求。

Thinking Machines 发布 Inkling 2 Mini

Thinking Machines Lab 发布开源权重模型 Inkling 2 Mini：它是 looped transformer，中间层每个 token 会跑三遍；总参数 264 亿，每 token 激活 34 亿，计入循环后约 54 亿，显存约占 20GB，可在笔记本电脑上本地运行。官方称，在总参数不到 1000 亿的开源权重模型里，它在 DeepSWE v1.1（48.2%）和 Vals Index v2.2（46.5%）领先，并同步放出用于研究循环深度的可变循环版本，已在 Tinker 上提供推理和定制。

Signal 限制手机截屏以防 AI 读取

Signal 总裁 Meredith Whittaker 称，Windows、Android 和 macOS/iOS 把智能体级 AI 做进操作系统后，屏幕上的敏感信息可能被采集并送到本地或远程，Signal 无法再独立保证会话隐私，她称之为“生存威胁”。该应用此前已默认禁止 Windows 客户端截屏，现在把类似限制加到了 Android 和 iOS；用户仍可自行关闭，但她承认这并不完整，挡不住智能体获取应用数据的其他途径。

亚马逊：AI 智能体 11 分钟内发现并利用零日漏洞

亚马逊威胁情报披露：今年 9 月 8 日至 10 日，一组以中等把握被归为与中国有关联的威胁行为者，用开源渗透测试框架 Cairn 的自主 AI 智能体攻击东亚（中国大陆以外）多所大学。操作员只给出“获得 shell 访问权限”的目标；智能体在约 11 分钟内，从摸清开源医学影像标注软件 MONAI Label 的 API，到利用文件上传路径遍历任意写文件，随后在另一次会话中写入 Python 反向 shell 并拿到 root。亚马逊以高把握将其认定为当时的零日漏洞。维护方已发布 GitHub 安全公告并合并修复，但 VentureBeat 称最新发行版仍是 0.8.5，修复要等下一版，目前需按公告做缓解。对加固后的 Redis 等目标，智能体也曾连续工作约 16 小时仍未得手。VentureBeat 报道

Spring AI 2.1.0 正式发布

Spring AI 2.1.0 已正式发布，可从 Maven Central 获取，基于 Spring Boot 4.2，距 2.0.0 GA 五个月，包含超过 430 次提交、86 位贡献者。主要变化包括：支持 MCP 2026-07-28 无状态新协议、新增 DecisionModel API（是/否、多选、打分，并带概率）、更丰富的消息模型（推理和工具调用可完整往返），以及 Session API 等智能体编排基础；11 个向量库也支持写入和检索自己算好的嵌入。同期发布的 2.0.3 与 2.1.0 一并修复了 13 个 CVE。下一步是 12 月初开始孵化用于编排智能体的新项目 Spring AI Agent。

Spring Boot 4.2 与 Cloud 2026.0.0 发布

11 月 19 日 Spring Boot 4.2.0 正式发布，11 月 20 日以它为基础的 Spring Cloud 2026.0.0（代号 Paddington）也已 GA。Boot 4.2 的要点包括 AMQP 1.0、可选的 OpenTelemetry 语义约定、可执行 jar 启动更快，并开始弃用 RestTemplate / TestRestTemplate（改推荐 RestClient / RestTestClient）。Cloud 此版本把 Spring Cloud Bus 并入 Spring Cloud Stream（坐标不变），并修复多枚安全漏洞，其中包括 Config Server 凭据泄露（CVE-2026-59435）、Gateway 本地响应缓存跨路由泄漏，以及 Spring Cloud Kubernetes 经 ConfigMap/Secret YAML 的远程代码执行（CVE-2026-59434）。
