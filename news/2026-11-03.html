大公司动态 2

Marvell 拟 1150 亿美元全股票收购 Lumentum

Marvell 宣布以全股票方式收购光器件厂商 Lumentum，每股换 4.5 股 Marvell，隐含企业价值约 1150 亿美元、溢价约 24%；交易后 Marvell 股东持股约 67%，预计 2028 年上半年完成。这是今年最大的 AI 押注之一，剑指博通，把电互连和激光、光模块、光交换整合到一家。（Marvell 官方公告，11-02）

Marvell 投资者关系 ↗MarvellLumentum并购光互连

OpenAI 在阿布扎比签下四份协议

Sam Altman 会见阿布扎比王储后，OpenAI 与 ADNOC（能源）、穆巴达拉（投资分析）、Inception42（五年期政企教育合作）签约，并与阿布扎比政府启动“机器可读政府”项目：把法规转成 AI 可读格式辅助审批，首个试点已在食品进口审批上线，全部在阿联酋境内 GPU 上推理。（阿布扎比媒体办公室，11-02；CNBC 报道）

Abu Dhabi Media Office ↗OpenAI阿联酋政务 AI

新模型和产品 2

美团发布 LongCat-2.5，全程国产算力训练

美团发布原生多模态模型 LongCat-2.5，总参数 1.6 万亿、每 token 激活约 480 亿，1M 上下文，主打长程智能体编程和视觉编程；官方称多项评测介于 Claude Opus 4.8 和 Opus 5 之间，官网可体验并同步开放 API。（美团，11-02；技术博客）

美团 ↗美团LongCat国产算力

小米 MiMo-V2.6-Pro 开源，MIT 协议

小米新旗舰 MiMo-V2.6-Pro 是 1.02 万亿参数（激活 420 亿）的全模态 MoE，1M 上下文、MIT 协议；小米自报 DeepSWE 从 19.0 跳到 71.9，接近 Claude Opus 5 的 74.0（厂商自测数据）。DeepInfra 已上线，输入每百万 token 0.435 美元。（DeepInfra，11-01）

DeepInfra ↗小米MiMo开源模型

融资 2

Trajectory 获 4500 万美元 A 轮，让专家自己训模型

由三位斯坦福同学创办的 Trajectory 完成 4500 万美元 A 轮，估值 3 亿美元，红杉领投、英伟达等跟投；它做“持续学习”后训练平台，让律师、金融分析师等根据反馈自动改进开源模型，客户包括 Harvey、Rogo、Decagon，平台现已公开。（TechCrunch，11-02）

TechCrunch ↗后训练红杉A 轮

42AI 携 6250 万美元种子资金走出隐身

以色列公司 42AI 做“行为世界模型”，预测个人在新情境下的行为，已在 10 家大型券商用于预测交易者在波动行情中的反应；6250 万美元种子资金来自创始人和 Infinity Group，分三年投入。（TechCrunch，11-02）

TechCrunch ↗世界模型金融种子轮

政策与研究 2

韩国 2027 预算拿出 21.3 万亿韩元投 AI

李在明提出创纪录的 820.9 万亿韩元 2027 年预算，其中 21.3 万亿投向 AI 及芯片、物理 AI、AI 数据中心三大项目，另有 4.7 万亿用于打造世界领先的主权前沿模型；需国会在 12 月 2 日前批准。（韩联社，11-02）

韩联社 ↗韩国主权 AI预算

SemiAnalysis 推出 GDPx，最强模型只拿 12%

GDPx v1.0 包含 11 个高价值领域（芯片设计、网安、生物、法律、量化等）的 206 个长程智能体任务，首发榜单 Claude Opus 5.5 以 12.0% 领先，Gemini 4 Carbon 10.9%、GPT-6 Astra 9.6%；计划每 3–6 个月更新。（SemiAnalysis，11-02）

SemiAnalysis ↗基准测试智能体

Java 3

TornadoVM 8.0 换上纯 Java 编译器

TornadoVM 8.0.0 GA 用自研的纯 Java 编译器 TC 把 Java 内核编译成 CUDA C++、OpenCL C 或 Metal，取代用了十年的 Graal 编译器和 JVMCI，现有 TaskGraph、@Parallel 等代码无需改动；还利用 GraalVM Native Image 和 JEP 516 AOT 对象缓存加快启动。（InfoQ Java 周报，11-02）

InfoQ ↗TornadoVMGPULeyden

Eclipse JNoSQL 1.2.0 支持向量数据库

Jakarta NoSQL / Jakarta Data 实现 JNoSQL 1.2.0 新增 VectorTemplate 接口，集成 Milvus、Qdrant、Weaviate 做向量检索，并加入时序数据的流式时间查询，Java 做 RAG 多了一个标准化入口。（InfoQ Java 周报，11-02）

InfoQ ↗Jakarta Data向量检索

Gradle 9.9.0 RC1：Kotlin DSL 增量编译

Gradle 9.9.0 首个 RC 让 Kotlin DSL 脚本通过 Kotlin Build Tools API 增量编译以加快构建，还能对非方法声明的 JUnit Platform 测试加过滤器；同周 JDK 28 EA Build 22、JReleaser 1.27.0 也已发布。（InfoQ Java 周报，11-02）

InfoQ ↗Gradle构建工具
