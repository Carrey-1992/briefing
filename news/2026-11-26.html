FCC 批准 SpaceX 轨道数据中心星座

这是今天最明确的官方进展：美国联邦通信委员会有条件批准 SpaceX 部署最多 100 万颗用于轨道数据中心的卫星，等于给“把 AI 算力送上天”开了监管绿灯。反对意见来自亚马逊、Viasat 和美国天文学会，碎片、干扰和可行性都还没解决，首颗可运行卫星也有 7 年窗口、完整星座要 14 年，所以这不是马上能用的算力。但它把太空数据中心从构想推进成了获批的星座计划，也是当天最能改变行业想象边界的一条。相比仍待独立核验的数学预印本，这件事的事实更硬、影响也更直接。

大公司动态 3

FCC 批准 SpaceX 轨道数据中心星座

美国联邦通信委员会 11 月 25 日有条件批准 SpaceX 部署并运营最多 100 万颗卫星，用于轨道数据中心业务（卫星名为 Starmind）。TechCrunch 报道，亚马逊、Viasat 和美国天文学会曾以轨道碎片、频谱干扰和环境影响等理由反对，亚马逊称该申请“更像宏大设想而不是切实计划”，却又警告“可能造成真实损害”；FCC 认为部分关切超出其监管权限。主席 Brendan Carr 说，此举“为支撑美国领先地位所需的计算基础设施打开了大胆的新前沿”。批准并不等于马上能建：SpaceX 需在 7 年内把首颗可运行卫星送入轨道，并在 14 年内部署完整星座；600 公里以上卫星的碎片处置方案尚未获批，散热、制造与发射成本等问题也仍待解决。卫星计划运行在 500 至 1,002 公里高度，主要用激光与包括星链在内的其他卫星通信。

新规后市场上出现大量待售英伟达 B300

CNBC 11 月 25 日援引三位知情人士报道，美国商务部 11 月 16 日公布、19 日生效的限制对华远程调用先进算力新规之后，市场上出现异常大量的英伟达 GPU 求售，其中包含数千颗最先进的 B300。AI 基础设施交易平台 GPU Mart 总裁 Jack Duhamel 及知情人士称，抛售直接与新规有关，这些芯片原先计划用于让中国公司远程租用的海外数据中心。英伟达拒绝置评。美国贸易代表 Jamieson Greer 当天表示，新规是为堵住经东南亚走私或经第三国数据中心远程调用的漏洞。11 月 17 日简报已报道过这项规则本身，这是规则落地后的市场反应。

亚洲数据中心相关贷款因芯片新规停滞

彭博 11 月 25 日报道，美国收紧芯片获取限制后，银行已叫停或推迟与字节跳动、阿里巴巴和腾讯相关的数十亿美元数据中心贷款。知情人士称，贝恩资本旗下 Bridge Data Centres 一笔上调至 66 亿美元、服务对象包括字节跳动的马来西亚设施贷款被推迟尽调；有银行放弃向 Partners Group 支持的 Digital Halo 提供 3.72 亿美元全包销贷款（该马来西亚数据中心客户包括阿里巴巴）；面向新加坡 neo-cloud 公司 Aolani、业务来自字节跳动的 4.80 亿美元贷款也在被重新评估。报道还称，至少有一家基金决定不参与向英伟达云合作伙伴 GMI Cloud 提供 3 亿美元贷款，为腾讯使用的泰国数据中心购买芯片。新规要求新加坡、马来西亚、印尼、泰国和巴西的公司购买先进 AI 芯片须获美国许可证，已经向中国公司大量出租算力的数据中心也需另行申请，并有 90 天窗口。彭博统计，亚太数据中心贷款已从 2023 年几乎为零增至超过 490 亿美元。

新模型和产品 2

Claude 产物可安装为桌面应用

Anthropic 宣布，Claude 产物（artifacts）可在 Mac 和 Windows 上以测试版安装为桌面应用：有独立图标和窗口，不必开着 Claude 界面，也能发通知、放到菜单栏或系统托盘，并继续使用 Claude 与已连接的服务。权限分三档，从接近浏览器的默认权限，到可创建置顶窗口和全局快捷键，再到可运行程序、读写或删除文件的完全访问；完全访问只适用于自己或组织内制作的应用，而且每次更新都要重新授权。功能对所有方案开放测试，企业版默认关闭，须由管理员开启；使用时需在线并登录 Claude 账号，Docs、Slides、Sheets 等产物不能安装。官方页面日期为 11 月 24 日，媒体报道出现在 11 月 25 日。ZDNET 报道

Anthropic ↗AnthropicClaude

MCP 服务器可下发 Skills，Tasks 已正式可用

在 Model Context Protocol 两周年之际，Anthropic 宣布 Skills over MCP 已在 Claude 和 Claude Code 进入公开测试：MCP 服务器可以随工具一起下发技能和操作说明，Claude 只在需要时加载，以减少上下文占用。Tasks 和 Elicitation 已正式可用，前者让服务器在后台跑长时间任务，后者可在中途弹出表单或链接征求用户确认，例如删除仓库或执行破坏性 SQL；File Uploads 将在稍后推出，用于把文件交给服务器而不经过上下文窗口。Skills over MCP 对 Pro、Max 和 Ultra 默认开启，Team 需管理员打开。官方称 MCP 的 SDK 每月下载量已超过 7 亿次，Claude 上的连接器超过 1 万个。官方页面日期为 11 月 24 日。

政策与研究 2

OpenAI 预印本称矩阵乘法指数恰为 9/4

OpenAI 11 月 24 日在官方数学仓库新增预印本《The matrix multiplication exponent is nine fourths》，声称方阵乘法指数 ω 在任意域上都恰好等于 9/4（即 2.25）。文稿称，它为形式算术电路补上了与上界匹配的下界：当边长 n≥2 时，至少需要 ⌈n^(9/4)/2⌉ 次非标量乘法或除法。仓库说明，Lean 形式化目前证明的是不含除法的电路在任意域上的方阵指数为 9/4，并不覆盖全文。这仍是未经独立核验的预印本，OpenAI 以机构名义署名；该仓库今年 10 月也曾撤回过文稿，因此还需外部检验。同一批还发布了多篇其他声称结果，此处只记这条最受关注的主张。仓库合入时间约在昨日简报前一小时，讨论主要出现在简报之后。

42 个州检察长反对拍卖 Character.AI 聊天记录

加利福尼亚州总检察长 Rob Bonta 11 月 24 日宣布，一个由 42 名总检察长组成的跨党派联盟反对 Character.AI 在破产程序中出售平台及超过 2100 万个美国账户的私人聊天记录，其中超过 210 万个账户登记为未成年人，拍卖定于 12 月 1 日。检方称，该公司曾向用户承诺不会出售个人信息，但拟议交易未要求买受方遵守其隐私政策，也未限制转售。目前披露的唯一竞买人是 11 月 13 日在特拉华州成立的 Smirks and Pangs Acquisition LLC，次日即被定为基准报价；各州还要求法院拒绝其一笔 35 万美元的分手费。Character.AI 已于 10 月申请第 11 章破产。TechCrunch 报道

Quarkus 4.0 发布，最低要求 Java 21

Quarkus 11 月 25 日发布 4.0 正式版，官方称为筹备两年的新主版本。最低支持版本升至 Java 21，不再支持 Java 17，并推荐使用 Java 25；网络层迁移到 Vert.x 5 和 Netty 4.2，同时升级到 Jackson 3、CDI 5.0、Jakarta REST 4、Jakarta Persistence 4.0 与 Jakarta Data 1.1，以及 Hibernate ORM 8。新特性包括下一代数据访问层 Quarkus Data、可选的 HTTP/3 扩展、Dev UI 可观测性面板，以及把 Quarkus Agent MCP 作为配合 AI 编程智能体的推荐方式。这是一次带破坏性变更的主版本，官方提醒先阅读迁移指南再升级。Hibernate ORM 8.0 等组件尚在等待 Jakarta 相关规范的最终版，本期先带候选发布。

JDK 28 的 jlink 可写入安全属性

Inside Java 11 月 25 日发布面向 OpenJDK Quality Outreach 的提前提示：从 JDK 28 起，jlink 新增 security-properties 插件，可用 --security-properties=filename 在制作自定义运行时时改写生成镜像里的 conf/security/java.security，匹配项会被更新，新属性则追加到文件末尾。若属性文件含 include 语句，插件会把它放到生成配置的末尾，且不要求被引用文件在构建机上已经存在。详见 JDK-8381580。
