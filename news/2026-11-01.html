大公司动态 2

Apple Intelligence 12 月入华，接入阿里千问

苹果在中国官网宣布：11 月 4 日起随 iOS 开发者测试版开始测试，12 月随 iOS 27.3 正式推出；千问接入 Siri、写作工具和视觉智能，用户可自选是否启用，阿里称不用用户请求训练模型。首批不含新版 Siri AI，仅支持 iPhone 15 Pro 及更新机型。（新华社 10-31；9to5Mac 10-30 美国时间）

新华社 ↗苹果阿里千问

Cursor 扩展市场的 Claude Code 扩展被植入 SSH 后门

10-29 约 12 小时内，Cursor 市场上的 Anthropic.claude-code 2.1.312/2.1.313 被篡改，会写入攻击者 SSH 公钥、建立反向隧道并做持久化，最多约 5000 名用户受影响；官方 VS Code 市场和 npm 不受影响。装过这两个版本的需按 Cursor 公告 排查，仅卸载不够。（Ars Technica，10-31）

Ars Technica ↗供应链安全CursorClaude Code

新模型和产品 2

商汤开源 SenseNova Loop 9B 循环层模型

Apache 2.0 许可，把第 4–27 层重复跑两遍，只存 32 层权重却做 56 层计算（约 14.6B 推理参数），支持 26 万 token 上下文，面向长文档、编程和工具调用；目前是预览版，技术报告未发布。（TSN，10-31）

TSN ↗商汤开源多模态

Pika 开源 H3 Flex 音视频生成模型

基于 33B MiniMax H3 微调，采样从 50 步降到 6 步，768p 15 秒视频约 7 秒生成，可输出对白、配乐、音效等五条独立音轨；权重已上 Hugging Face，API 已开放。（Hugging Face，10-31）

Hugging Face ↗Pika视频生成开源

融资 2

OpenAI 本轮融资目标从 300 亿下调到最多 200 亿美元

CNBC 证实了《金融时报》的报道：本轮投后估值 1.25 万亿美元，部分投资人缩减认购额；这轮还没结束，条款可能变化。背景是科技股抛售和投资人对 AI 支出的审视加强。（CNBC，北京时间 11-01 03:56）

CNBC ↗OpenAI估值

AI 自主设计芯片公司 Phinity Labs 获 520 万美元种子轮

Uncork Capital 领投，Jeff Dean 参与，目标是用 AI 智能体从文字描述出发完成架构探索到流片的闭环芯片设计。（Economic Times，10-31）

The Economic Times ↗芯片设计智能体

政策与研究 2

美国约 20 个社区下周二投票限制数据中心

俄亥俄、佛州、缅因、堪萨斯等地将在 11 月 3 日的选举中表决是否禁止、暂停或限制数据中心建设，此前已有约 400 个社区出台禁令或暂停令，许多在共和党选区，被视为对特朗普 AI 基建政策的检验。（POLITICO，北京时间 11-01 02:00）

POLITICO ↗数据中心美国

Claude Sonnet 5 智能体自主选药并给小鼠做脑部注射

Exin Therapeutics 称智能体从 19 种基因疗法中自选药物、脑区和坐标，操控手术设备完成注射；中途发现校准错误后拒绝继续，团队只能手动改代码。Opus 5/5.5 直接拒绝执行。结果未经同行评审。（The Decoder，10-30）

IntelliJ IDEA 的 Java/Kotlin 扩展 1.0 登陆 Cursor 和 VS Code

JetBrains 把 IDEA 的 Java/Kotlin 能力做成 LSP 扩展（JetBrains.intellij-server），支持补全、重构、Maven/Gradle/Bazel、JUnit 和调试，并与 Cursor 合作支持智能体窗口；1.0 起试用 30 天后需 IDEA Ultimate 订阅，后续会让 Claude Code、Codex 等终端智能体直接调用。（JetBrains 博客，Baeldung 10-30 收录）

JetBrains Blog ↗IntelliJLSPAI 编程

Quarkus 4.0 时间表：11-04 CR1，11-25 正式发布

Quarkus 官方发布计划显示 4.0 Core CR1 提前一周到 11 月 4 日，Core Final 11 月 18 日，完整平台发布和官宣在 11 月 25 日；4.0 以 Java 21 为基线，升级 Vert.x 5、Hibernate 8、Jackson 3，现在是测试迁移的窗口。

Quarkus Wiki ↗Quarkus

Inside Java 汇总 JDK 27 的 G1/Parallel/Serial GC 变化

Thomas Schatzl 的文章（10-30 收录到 Inside Java）梳理了 JDK 27 停顿式 GC 的变化：G1 在所有环境都成为默认收集器，G1 不再按 MinHeapFreeRatio/MaxHeapFreeRatio 调整堆大小，并发标记启动更稳，Parallel GC 堆扩展和晋升阈值也有修正。升级 JDK 27 前值得对照一遍。

Thomas Schatzl ↗JDK 27GC
