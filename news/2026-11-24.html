英伟达董事会恢复黄仁勋 CEO 职务

英伟达 11 月 23 日宣布，董事会一致表决，立即恢复黄仁勋的总裁、首席执行官和董事职务。董事会主席 Harvey Jones 表示，在与黄仁勋多轮沟通后对其坦诚和领导能力感到满意，并在过程中听取了美国政府高层意见，因而相信复职不构成国家安全风险。独立董事委员会对“黄仁勋曾是外国情报行动目标”相关报道的调查仍将进行到底，黄仁勋表示支持并配合；公司同时新设由独立董事组成的国家安全与出口管制委员会，并开始招聘向提名与公司治理委员会汇报的首席合规官，且将继续配合政府调查。暂代 CEO 的财务官 Colette Kress 继续任 CFO。特朗普称自己“完全参与”了此事，并在 Truth Social 上称这是“正确且恰当的决定”，还说司法部长已确认美国政府没有他从事违法活动的证据。CNN 报道，英伟达股价当日收涨 31.48%，盘中最高涨约 36.6%，单日市值增加约 9520 亿美元，为 2003 年以来最佳交易日；纳斯达克涨 6.51%，标普 500 涨 4.73%。CNN 报道

亚马逊已签约收购 Decart 优化技术

亚马逊 11 月 23 日宣布，已签署协议购买 Decart Optimization Stack（DOS）的专有技术，并引入联合创始人 Dean Leitersdorf、Moshe Shalev、Orian Leitersdorf 及其研究人员和工程师团队。官方称，该技术将用于进一步优化推理和自研芯片（包括 Trainium）的性能，双方自 2025 年起已有合作。交易仍须满足惯例交割条件，包括监管批准。亚马逊未公布交易金额；TechCrunch 援引彭博社报道称约为 75 亿美元。这是对昨日简报“接近收购、尚未签约”的更新。TechCrunch 报道

Anthropic 推出 Claude Ship

Anthropic 11 月 23 日发布 Claude Ship（测试版）：Claude 可以审查拉取请求、动手修改，并按团队写在仓库里的策略决定哪些变更可以批准。它由三部分组成：已正式可用的 Code Review，以及仍处测试阶段的 PR Steward 和 Claude Approvals。开发者可在 Claude Code 里用 /ship 命令走完推送、开 PR、审查和修反馈的流程；管理员也可按仓库开启，并建议先用只观察模式。目前面向 Claude Team 和 Enterprise 方案、且代码托管在 GitHub 的仓库，用量按 token 计费。

OpenAI 与 Cisco 开源 Shirudo

OpenAI 与 Cisco 11 月 23 日推出开源运行时 Shirudo（日语“盾”的意思），用 eBPF 在 Linux 系统仍在运行、补丁尚未完成部署时加上临时防护，无需重启。官方举的受控测试是：用 Codex 生成的防护在正在运行的 Elasticsearch 上挡住了一次 Java4Shell 利用，服务没有中断。防护在加载前需加密签名并校验，还可用 TPM 留下可验证记录。项目以 BSD 2-Clause 开源，BPF 程序采用 BSD 与 GPL 双许可，双方邀请开发者和安全人员一起贡献，并计划在漏洞披露时同步提供经过测试的临时防护。

OpenAI 推出 OpenWorks 扶助小企业

OpenAI 推出 OpenWorks 试点：在美国 20 个社区组建本地合作伙伴，为独立经营的小企业提供免费、当面的 AI 使用指导，参与企业还可获得三个月免费的 ChatGPT Business。合作伙伴每月可获最高 8,000 美元津贴，需承诺每月四天现场服务并举办一场社区工作坊。试点面向餐馆、零售、服务业和制造业等，不包括软件或 SaaS 公司，以及风险投资或私募股权支持的企业。

Micronaut 5.2.8 发布安全更新

Micronaut 11 月 23 日发布 5.2.8，这是一次安全版本，更新至 Micronaut Security 5.4.3（修复 14 项 GitHub 安全公告）和 Micronaut Servlet 6.2.3（修复 3 项，其中 1 项为严重）。最紧急的是：在 Tomcat 和 Undertow 上，micronaut.ssl.client-authentication 此前未被强制执行，没有证书的客户端也能通过双向 TLS。另外还有 POJA 运行时的请求走私、JDK HTTP 服务器路径双重解码等问题。官方强烈建议所有用户升级；若仍在使用 Micronaut 4，应对应升级到 4.10.25。部分修复会改变默认行为，升级前需要核对说明。
