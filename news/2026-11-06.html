OpenAI 发布 GPT-6 Cyber，网络安全能力升至 Critical

大公司动态 2

谷歌宣布怀俄明州首个数据中心，投资 170 亿美元

谷歌将在拉勒米县建设怀俄明州首个数据中心，与 Tallgrass、Black Hills Energy、AEP、Related Digital 合作；配套 702 兆瓦燃料电池并做碳捕集封存，谷歌承诺自担全部用电与直接相关基建费用，采用空气冷却以减少用水。宣布恰逢中期选举后多地限制数据中心。（Google 官方，11-05；Reuters）

Google ↗谷歌数据中心基建

美股 AI 抛售：纳指跌 5.5%，英伟达跌超 9%

美东 11-05 纳斯达克综指跌 5.5% 进入回调区间，标普跌约 4.4%，七巨头合计市值蒸发超 1 万亿美元；英伟达跌逾 9%、单日市值损失超 4400 亿美元并转年内下跌。市场担忧中期选举后数据中心审批趋严、AI 资本开支回报与交付风险。（CNBC，北京时间 11-06 清晨）

CNBC ↗美股英伟达AI 基建

新模型和产品 3

OpenAI 发布 GPT-6 Cyber，网络安全能力升至 Critical

专用安全研究模型 GPT-6 Cyber 在 ExploitGym 得分 48.5%，相对 GPT-5.6 Cyber 的 32.1% 提升约 51%；已为 Linux 948 个提权漏洞开发可用 exploit，并在 Firefox 发现 81 个未知高危漏洞。准备度框架下网络安全评级从 High 升至 Critical，目前仅向审核通过的 Daybreak Red 客户开放 API/Codex。（OpenAI 官方，11-05）

OpenAI ↗OpenAI网络安全GPT-6

谷歌发布 Gemini Omni 1.2 Flash，原生 15 秒视频并降价 30%

Omni 1.2 Flash 将原生视频长度从 10 秒提到 15 秒，支持多轮对话式剪辑与更强参考图一致性；720p 约每秒 0.07 美元，较 1.1 降价 30%，已在 Gemini API 与 Google Cloud 正式可用，并带 SynthID 水印。（Google DeepMind，11-05）

Google ↗谷歌Gemini视频生成

英伟达开放 Cosmos 3 交互式世界仿真检查点

基于 Cosmos 3 Nano（160 亿参数）后训练的四个开放权重检查点上线：Transfer-Auto、Sim-Auto（多视角驾驶+LiDAR）、Sim-Transfer、Sim-Bimanual（双臂机器人），面向自动驾驶与机器人交互仿真，许可证为 OpenMDW 1.1。（Hugging Face，11-05）

Hugging Face ↗英伟达Cosmos世界模型

政策与研究 2

OpenAI 发布社区契约：不对公职人员签 NDA、自担电费

中期选举多地反对数据中心后，OpenAI 发布 National Community Compact 与政策蓝图：自有运营的 compute campus 不对公职人员使用 NDA（仅保留安全/商业秘密等狭窄例外），自担全部电费与相关基建，并公开就业与用水用电报告。（OpenAI 官方，11-05；The Verge）

OpenAI ↗OpenAI数据中心政策

约 60 万颗英伟达 H200 滞留香港，北京未批大规模进口

路透援引知情人士称，约 60 万颗 H200 暂存香港待运内地；近期仅少量放行，阿里、字节、DeepSeek、腾讯等大型互联网公司近数月各获约 1 万颗。北京对大规模进口仍未批准，显示国产替代与对美依赖之间的政策拉扯。（Reuters / Investing.com，11-05）

Reuters ↗中国英伟达芯片管制

Spring AI 2.1.0-RC2 发布：DecisionModel 与 MCP modern 协议

新增 DecisionModel API（含 Ollama/SystemOne 实现）、DecisionToolIndex 工具搜索、基于决策的 RAG 文档后处理，以及 MCP 2026-07-28（modern）服务端支持；工具调用参数支持流式 delta，Anthropic Java SDK 升至 3.4.0。（GitHub，北京时间 11-06 00:06）

GitHub ↗Spring AIMCP发布

Micronaut 5.2.5：升级 Netty 修复多枚 CVE

安全版本将 Netty 升至 4.2.20.Final，覆盖缓冲区越界读、HTTP/2 与 MQTT 无界内存、mTLS 会话恢复绕过等漏洞；同步发布 4.10.23 与 Core 3.10.18 覆盖各支持线，建议尽快升级。（Micronaut 官方，11-04）

Micronaut ↗Micronaut安全Netty
