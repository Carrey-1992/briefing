开发者工具 3

Gander（Quick Look 增强）

给 Finder 空格预览补上开发者文件的免费扩展（对标 QLMarkdown、QuickLookJSON 这类一种格式一个插件的方案），选中文件按空格就能看 GitHub 风格渲染的 Markdown（含 Mermaid 图）、JSON/JSONL、YAML、TOML、SQL、SQLite、日志（最新行在上并可只看报错）、.env（值默认隐藏）和含 Java、Kotlin 在内 30 种语言的代码。11 月 7 日在 MacPip 发布，当前 1.4 版。官网标注：免费，无内购、无订阅、无网络访问，需 macOS 15+。

MacQuick Look开发者免费

Relai 0.36（子 Agent 视图）

把 Claude Code、Codex、opencode、Cursor、Gemini CLI 等 10 种编程 Agent 的本地会话汇到一个窗口的「控制室」（对标各家 CLI 自带的历史记录）。11 月 3 日的 0.36 新增 Agents 视图：一层层展开主会话派生的所有子 Agent，标出失败、没回报或耗 token 超过同批中位数 3 倍的那几个，还能按 Agent 看 token 和成本；官网现已到 0.38.0。官网价：14 天免费试用，Pro 9.99 加元/月或 99 加元/年；Mac 版只支持 Apple 芯片。

MacAgent开发者

Mole v1.19.1

集清理、卸载、磁盘分析、菜单栏状态监控和应用更新于一身的 Mac 维护工具（对标 CleanMyMac + iStat Menus）。11 月 5 日的 v1.19.1 对开发者很实用：清理项新增 30 天没用过的 Gradle 版本、编程 Agent 留下的 Xcode 构建数据，AI 清理页会列出已合并进 main 的 Agent worktree；菜单栏可看每个 App 的网络用量并内置测速，应用更新里 Homebrew 包和其他 App 合并到一个列表，JetBrains IDE 会显示新版本。

Mac清理系统工具

搜索与窗口管理 2

Espresso

Mac 上的 Everything（对标 Windows 的 voidtools Everything，也比 Spotlight 更适合按文件名精确找），给所有磁盘的文件名建索引、边打字边出结果，支持 Everything 的 AND/OR/NOT、通配符、正则、ext:、dm: 等语法，拔掉的移动硬盘也能继续搜；⌥空格全局呼出。Pro 版另有命令行 espresso、Raycast/Alfred 扩展和只读 MCP 服务器。11 月 6 日在 MacPip 发布，当前 0.2.1。据 MacPip 收录信息：个人使用免费，Pro €19；官网说明工作用途需要 Pro。

Mac文件搜索MCP

LanesMac

滚动式平铺窗口管理器，把 Linux 上 PaperWM、niri 的玩法搬到 Mac（对标 AeroSpace、yabai，但新窗口不会把别的窗口挤窄）：每个窗口是一条横向长带上的整高列，按 ⌃⌥ 加方向键或双指横扫滚过去；支持堆叠列、标签列、每块显示器独立一条带、重启后恢复布局，还有 lanesmac 命令行和 JSON 布局存取。11 月 8 日在 MacPip 发布。官网价：24 小时免费试用后 $19.99 买断（单台 Mac），需 macOS 13+，只要辅助功能权限、不用关 SIP。

Mac窗口管理买断

AI 助手与办公 2

Mobeera Office（Mac / iPhone / iPad）

11 月 7 日上架 App Store 的办公套件（对标 Microsoft Office、iWork），Docs、Sheets、Slides、PDF 四个编辑器，直接读写 .docx/.xlsx/.pptx。三端都有 AI Chat，用你自己的 Anthropic、OpenAI、OpenRouter 或本地兼容模型的 Key；Mac 上还能通过 MCP 让 Claude、Codex、Cursor 等直接改文档，改动先预览、可一步撤销，Word 里以修订形式出现。官网价：一次买断，早鸟期按每 100 份阶梯涨价（目前 US$19.99 起，最高 US$49.99），12 月 3 日起 US$99；Mac 版需 Apple 芯片和 macOS 14+。

MaciOS办公MCP买断

webAI（Mac 端侧 AI）

11 月 5 日首次公开发布的 Mac 应用，在本机跑 webAI 自家的小型推理模型（对标 ChatGPT、Claude 桌面版，但文件不上云、没有按 token 计费）。可以建多个「Persona」各司其职协作完成一件事，并通过连接器接 Slack、DocuSign、Hugging Face 和苹果自带应用，每个 Persona 能访问什么、能做什么由你控制。适合处理不想发到云端的私密文档；官方公告未写价格。

任务与日程 1

Tasks 5.4（Mac / iPhone）

跨 iPhone、iPad、Mac、Apple Watch 的任务管理应用（对标 Things、OmniFocus，可接苹果提醒事项）。11 月 5 日的 5.4 补上全局撤销/重做（iPhone 摇一摇也行，删掉的任务连子任务、评论一起回来）；Mac 端新增 tasks 命令行，可装成 Claude、Codex、Cursor 的 Agent skill，tasks mcp 还能在本机起一个不经云端的 MCP 服务器；Mac 应用全程可键盘操作。命令行属于 Tasks Plus 功能，官网此页未写价格。
