开发者工具 1

Jikoo

11 月 22 日公开的早期免费应用：在你的 Mac 里再开一台独立的电脑（chamber），预装 VS Code 以及 Claude Code、Codex、Gemini CLI，智能体只能看到你主动共享的文件夹，删掉 chamber 不会在本机留下痕迹（对标自己配虚拟机，或给 Agent 开系统级全盘权限）。官网：早期免费，若改为付费会至少提前 30 天通知；需 Apple 芯片、macOS 13+，建议 16GB 内存，约 20GB 磁盘空间。

MacAgent沙箱免费

启动器与系统工具 2

Raycast v2.13（重要更新）

第 1、3 期推荐过，这次值得再提：11 月 18 日的 v2.13 新增本地 Raycast MCP，可把 Claude、Codex、Cursor 接到 Raycast，用来搜索剪贴板、创建片段和 Quicklink、管理应用和浏览器标签等，分享哪些扩展由你决定，全部在本机运行。同一周的 iOS 1.5.5 让听写直接在键盘里完成，不用跳回 App。官网：个人使用免费（含启动器、剪贴板历史、窗口管理等内置扩展）；AI 功能需 Pro。

MaciOS启动器MCP

Helix

径向菜单式启动器（对标把启动器、剪贴板、截图等小工具收进一个快捷键，类似游戏里的武器轮盘）：按住 ⌥空格（可改）在指针旁弹出圆环，指向即用。内置剪贴板、截图、窗口吸附、备忘录、提醒事项，以及用你自己的 API Key 问 Claude 或 GPT 等共 16 个工具。无账号，数据留在本机。官网价：$9 买断（含后续更新，最多 2 台 Mac），7 天试用；需 macOS 14+。

Mac启动器买断

窗口管理 2

Split

专注双窗口并排的窗口管理器（对标 Rectangle、Magnet 的分屏，但多了一条共用分隔条）：用快捷键或拖放把两个窗口配对后，拖分隔条两边一起改大小，点一下还能左右对调。官网价：$4.99 买断（含后续更新，同一时间 1 台 Mac）；需 macOS 13+，支持 Apple 芯片和 Intel。

Mac窗口管理买断

Stage Manager（开源替代）

免费开源的台前调度替代（对标系统自带 Stage Manager）：重启后舞台会按原顺序回来，可以把两个舞台合成一个，并支持 ⌃⌥1–9 切换或把窗口送到指定舞台。看起来和系统版一样，不用这些增强时行为也一致。已签名公证；需 Apple 芯片、macOS 14+，也可用 Homebrew 安装。

Mac窗口管理开源免费

剪贴板、笔记与日程 3

Unclutter 2.3

从屏幕顶部下滑打开的「桌面搁板」（对标把剪贴板历史、临时文件和速记笔记放在一起）。11 月 20 日的 2.3 适配 macOS 27：剪贴板历史可搜索，笔记支持 Markdown（可与 Obsidian 仓库共用），并新增 22 个快捷指令动作。Mac App Store 标价 $32.99 买断（无订阅，支持家人共享）；也可通过 Setapp 获取。需 macOS 10.13+。

Mac剪贴板笔记快捷指令买断

Clipster

本周介绍的跨设备剪贴板（对标 Paste、系统剪贴板），可用于 Mac、Windows 和 iPhone，能搜索历史并用 Pins 按主题归类。官网：免费版无需账号，保留 40 条历史并提供全文搜索；Pro 可把历史扩到 250 条，并提供跨设备同步和加密备份，具体售价需在应用内查看（官网未标出金额）。

MaciOS剪贴板

Karu

把日历、提醒事项和笔记放在「每一天一页」里（对标 Fantastical + NotePlan 的组合），Mac、iPhone、iPad 可用；笔记是你指定文件夹里的纯 Markdown，无账号，可用 iCloud Drive 同步，也方便给 Claude Code 等直接读。官网：应用本身在 App Store 免费；可选 Pro 礼包为买断，Unlock everything 首发 $6.99，或单独购买 Personality $2.99、Meetings $4.99、Widgets $1.99。需 macOS / iOS / iPadOS 26。

MaciOSiPad笔记日程免费

输入与听写 1

Speaklively

本地听写工具（对标 Superwhisper、系统听写）：按住 fn（可改）说话，文字会一边说一边出现在当前输入框。转写和基础整理都在本机，音频不上网。官网：听写永久免费、无字数上限、无需账号；需 macOS 26 和 Apple 芯片（不支持 Intel）。可选的 AI 润色目前可用自己的 Anthropic Key；其按次套餐官网写明结账尚未开放。
