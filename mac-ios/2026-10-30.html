系统级 AI 助手与自动化 3

Brello for Mac

10 月 28 日发布，把文件归类、Mac 健康检查、清理和「用一句话改设置」放在一起，还有一个用苹果端侧模型干杂活的 Agent（如把收据整理成报销 PDF 并起草邮件），可设「每周五 5 点」这类例行任务。对标 CleanMyMac + Eney 一类助手。官网价：首发 $20、之后 $50 买断，最多 3 台 Mac；Agent 需 Apple 芯片 + macOS 27 + Apple Intelligence。

Mac助手买断

快捷指令 · iOS / macOS 27.2 更新

10 月 26 日随 27.2 推送：新增 iPhone Duo 开合自动化，「打开/关闭 App」自动化能拿到被关掉的 App 名，「Use Model」联网查询新增法、日、韩、葡、西语，iOS 上可直接在库里改快捷指令名称和图标。配合 27 版的自然语言建快捷指令、Markdown 写备忘录，值得重新整理一遍自动化。

iOSMac快捷指令

Deflector

免费 iPhone 小工具（MacStories 介绍），利用 iOS 27 新的「收到通知」自动化触发器，在灵动岛或锁屏实时活动里一点就运行任意快捷指令，不用跳进快捷指令 App。适合把常用指令和操作按钮分成两组用；点击后约有 1 秒延迟。

iOS快捷指令免费

窗口管理与输入 2

Tangrid 1.6.10

平铺窗口管理 + 窗口切换器 + Dock 预览三合一，对标 Rectangle/Aerospace 加 AltTab。10 月 11 日的 1.6.10 让窗口切换器启动快约 30%，竖排模式按空格或直接打字即可搜索窗口；1.5 起支持一键恢复整套工作区（浏览器 URL、文档、Shell 命令）。

Mac窗口管理

Haptiker

菜单栏小工具，把触控板四条边变成控制条：右边调音量、左边调亮度（外接显示器经 DDC/CI，限 Apple 芯片）、上边调键盘背光、下边轻划切换 App。10 月中旬的 1.1.x 加了按住 fn/Option 才生效和双击预设。官网价：$4.99 买断，7 天试用，可装 3 台 Mac。

Mac触控板买断

开发者工具 3

Otty 1.6

原生终端，定位介于普通终端和完整 Agent 开发环境之间，对标 Ghostty/Warp。10 月 18 日的 1.6.1 加了 Inbox：等审批、报错、正在跑的标签页排在前面并显示 Agent 当前步骤，Claude Code、Codex、Cursor、Grok 等都支持；10 月 25 日的 1.6.4 补了分屏快捷操作。

Mac终端Agent

SupaYatta

住在刘海（或悬浮条）里的 Agent 状态灯：Claude Code、Codex、Cowork、Cursor、OpenCode 跑完、提问或要审批时提醒，带回复预览并一键跳回对应终端标签，还能看 Claude/Codex 额度和重置倒计时。全部本地运行，无账号。据 TheMacApps 收录信息：$4.99 买断，7 天试用。

MacAgent刘海

Linelark Notepad 1.20.0

永久免费的原生文本/代码编辑器（官网写明无订阅、无遥测），10 月 24 日的 1.20.0 让终端像 VS Code 一样分组、拆分、合并，并给编辑器自带的 MCP 服务加了 list/read/send_to_terminal，Claude Code 可以读写其他终端（输入前必须确认）。适合想要比 VS Code 轻的编辑器。
