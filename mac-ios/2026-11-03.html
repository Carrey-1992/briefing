开发者工具 3

Ghostty 1.4.0

免费开源的原生终端（对标 iTerm2、Warp），10 月 27 日发布 1.4.0 大版本：macOS 上 I/O 吞吐提升 25%–55%，空闲滚动缓冲自动压缩（物理内存省 70%–90%，默认上限从 10MB 提到 50MB），20 个后台标签页的显存从约 385MiB 降到 18MiB；新增 ghostty +ssh 自动给远程机装 terminfo，并适配 macOS 27。注意 macOS 上 copy-on-select 默认改成了关闭，另修复了一批安全问题，建议尽快升级。

Mac终端开源免费

Coincide

11 月 1 日发布的免费开源（MIT）Mac 应用，把 Claude Code、Codex、Cursor、Grok Build、OpenCode、Antigravity 放进一个窗口并排跑；线程中途可从一个 Agent 交给另一个，新 Agent 会拿到前情摘要接着干，内置 Git diff、每轮检查点、worktree 和 PR，退出应用后任务仍在后台跑。用的是你自己各家 CLI 的登录或 API Key，不经过它的服务器。需 macOS 26 及以上。

MacAgent开源免费

SpaceWise

专给开发者的磁盘清理工具（对标 CleanMyMac、DaisyDisk），能找出闲置项目的 node_modules、Gradle/Cargo/pip 等包缓存、Docker 悬空镜像和构建层、Xcode DerivedData 和本地大模型权重；删除前会核对锁文件和 Git 活跃度，删的东西进废纸篓可一键恢复，全程本地扫描。10 月 31 日在 MacPip 上架。官网价：$7.99 买断，3 台设备（Mac 和 Windows 通用）。

Mac清理开发者买断

启动器与窗口管理 2

Raycast v2.10（重要更新）

第 1 期推荐过，这次值得再提：10 月 28 日的 v2.10 让 Notes 支持插图和 GIF，免费版取消 5 篇笔记上限；AI Chat 的 @ 菜单可以直接搜索并引用 AI 扩展里的内容。之前 v2.6–v2.9 连续做性能优化：宿主进程内存减约 50%，文件搜索最快 6 倍，根搜索快 50%，还新增了「重启当前 App」命令。

Mac启动器AI

Snug

菜单栏自动平铺窗口管理器（对标 Rectangle、Aerospace，但不用手动分屏），新窗口一打开就落进下一个空位，关掉一个其余自动补位；每种显示器组合记一套布局，插上外接屏桌面就复原，超宽屏有「Center Stage」把主窗口放中间。只读窗口位置和所属 App，不要屏幕录制权限。需 macOS 15+，11 月 1 日上架。据 MacPip 收录信息：$14.99 买断。

Mac窗口管理买断

笔记、日程与输入 3

Woday

11 月 2 日发布的原生 Mac 日程规划工具，把待办、日历、提醒事项和笔记放在一个界面里看一天的安排，对标 Fantastical + Things 的组合；和苹果日历、提醒事项双向同步，加进 macOS 的 Google/Outlook 日历也能显示。数据存在本机，无需账号，可选自己的 iCloud 同步。开发者页面价：早鸟 $19 买断（含 1 年更新、2 台 Mac），之后续更新 $10/年，14 天可退款。

Mac日程买断

Arion 0.1.1

11 月 1 日的首个稳定版，免费开源（AGPL-3.0）的本地语音 + 拼音输入法，对标 Superwhisper、微信输入法语音：按住右 Option 说话、松开打字，中英混说（如「把这个 PR merge 到 main 之前，先跑一下 CI」）也能识别；本地 Qwen3-ASR 1.7B 模型，下载约 2.5GB 后离线可用。还带可选的本地润色、按右 Command 语音翻译、离线全拼键盘和加密剪贴板历史。仅支持 Apple 芯片、macOS 14+。

Mac输入法语音开源免费

NoteOwl

全本地运行的 Mac 会议记录工具（对标 Granola、Otter），不用往会里拉机器人，直接录麦克风和系统声音，支持 Zoom、Meet、Teams 等；转写、区分说话人、生成摘要和待办都在本机完成，支持 34 种语言。需 Apple 芯片、macOS 26+、至少 16GB 内存。官网价：听写永久免费，Pro 会议功能 $79 一次买断（1 台 Mac），可试用 7 天。
