Java × AI 工具全景清单

2026-10-21 周三 · 51 条 · 已读 0
🚀 最值得上手
1. Spring AI（国内场景可以配 Spring AI Alibaba）
和你的 Spring 技术栈直接对得上，学会 ChatClient、工具调用、RAG、MCP，基本就掌握了 Java 接 AI 的主流做法。
2. IntelliJ MCP Server + Claude Code/Junie + Spring Skills
一套配置让 Agent 真正"看懂"你的 Spring 项目，提效最明显。
3. Context7
几分钟就能装好，能大幅减少 AI 写出过时 Spring API 的情况。
4. Arthas MCP
Java 开发者特有的优势，让 AI 直接做线上 JVM 诊断，排障效率提升明显。
5. OpenRewrite
升级 JDK 和 Spring Boot 4 时最稳的底座，再配合 Copilot 或 Amazon Q 处理剩下的部分。
全部Java 应用接 AI 的框架面向 Java 开发的 MCP 服务器AI 编程助手和 Skill/规则代码质量、测试、迁移运维和可观测JVM 平台本身跟 AI 相关# Skill 库

Java 应用接 AI 的框架 9

Spring AI

Spring 官方 AI 框架，统一封装 20 多家模型、工具调用、RAG、对话记忆、向量库，还有 MCP 客户端/服务端 Starter 和注解。Spring Boot 项目首选。

LangChain4j

最流行的 JVM LLM 库，不绑定框架，统一模型和向量库 API，支持工具调用、MCP、Agent、RAG，能和 Quarkus、Spring Boot、Helidon、Micronaut 集成。

Quarkus LangChain4j

Quarkus 的 LangChain4j 扩展，支持声明式 AI Service、GraalVM 原生编译，自带指标和链路追踪。

Spring AI Alibaba

阿里基于 Spring AI 做的 Agent/工作流/多智能体框架，带 Graph 编排、Nacos MCP 注册和 Admin 观测评估平台，国内模型和阿里云生态接得最顺。

Semantic Kernel for Java

微软的 AI 编排 SDK，提供插件、记忆、规划，和 Azure 集成得深。

Google ADK for Java

Google 开源的代码优先 Agent 工具包，支持多智能体编排，自带 Dev UI，偏 Gemini/Google Cloud。

Embabel

Spring 创始人 Rod Johnson 发起的 Agent 框架，用 GOAP 做确定性规划，工作流有类型；既能当 MCP 服务端也能当客户端，项目比较新。

MCP Java SDK

MCP 官方 Java SDK，和 Spring AI 团队合作维护，用来写 MCP 服务端或客户端。

AI4JVM

汇总 JVM AI 框架和动态的导航站，适合定期翻看（A2A Java SDK、AgentScope Java 等新项目也能在这里看到）。

面向 Java 开发的 MCP 服务器 15

IntelliJ IDEA MCP Server

IDEA 2025.2 起内置，让 Claude Code、Codex、Copilot CLI 等外部 Agent 调用 IDE 的能力，比如读项目结构、跑配置；能自动帮客户端写好配置。

Arthas MCP Server

（源码） 把 Arthas 的诊断命令开放给 AI，涵盖 JVM 监控、类加载、方法追踪等，可以直接让 AI 排查线上 Java 问题。目前是实验模块。

Context7

给 Agent 实时拉取各类库的最新文档（Spring、MyBatis 等），减少 AI 编造过时的 API。支持 MCP 和 CLI+Skill 两种接法。

Maven MCP Server（Bigsy）

查 Maven Central 上依赖的最新版本。

mvn-mcp-server

查依赖版本、分析 POM，还能用 Trivy 扫安全漏洞。

mcp-java（MySQL）

MySQL MCP，支持查询、执行、看表结构、EXPLAIN，适合让 AI 帮你分析慢 SQL。社区项目。

Redis MCP

Redis 官方 MCP，用自然语言查看和操作 Redis 数据。

mcp-confluent

Confluent 官方 Kafka MCP，支持 Confluent Cloud/Platform 和自建 Kafka，可以管理 topic、查看消息。

Elasticsearch MCP

Elastic 的 MCP 服务，这个仓库已经弃用，Elastic 9.2 以上改用 Agent Builder 内置的 MCP。

Kubernetes MCP Server（containers）

用 Go 原生实现，直接调 K8s API，可以看 Pod、日志、事件，也能操作 Helm 和 Tekton。

mcp-server-kubernetes（Flux159）

封装 kubectl 和 Helm，带 k8s-diagnose 排障提示词，支持非破坏模式和 Secret 脱敏。

Prometheus MCP

Prometheus 社区的 MCP，让 AI 直接查指标。

Grafana MCP

Grafana 官方 MCP，让 AI 查看仪表盘和数据源。

SkyWalking MCP

Apache 官方 MCP，查询 SkyWalking OAP 里的链路、日志、指标、拓扑和告警，对 Java 微服务排障很有用。

Greptile MCP

在 Agent 里拉取 Greptile 的审查意见并修复。

AI 编程助手和 Skill/规则 10

JetBrains Junie

JetBrains 的编码 Agent，不绑定模型，能在 IDE、终端和 CI/CD 里跑，对 Java 项目的理解是它的优势。

GitHub Copilot 现代化升级（Java）

用 Agent 升级 JDK、Spring Boot 4、Jakarta EE 11，会自动验证构建和测试、修复 CVE。（GitHub 教程）

Cursor Skills

Cursor 支持 Rules 和 Skills，可以从 .cursor/skills 或 .agents/skills 加载团队规范。

Claude Agent Skills

Claude Code 的 Skill 机制；Skill 是一个带 SKILL.md 的文件夹。Agent Skills 规范是开放格式，多家工具通用。

通义灵码

阿里的编码助手，支持 VS Code、JetBrains 和 Lingma IDE，提供补全、问答、报错修复和编程 Agent。

文心快码 Baidu Comate

百度的 AI 研发助手，偏企业和中文场景。

CodeGeeX

智谱开源的多语言代码模型，有 VS Code 和 JetBrains 插件。

Amplicode Spring Skills

面向 Spring Boot 的 Skill 集，覆盖项目探索、JPA/JDBC、REST、Security、Kafka 配置、测试覆盖率、PIT 变异测试、IDEA 调试，可配合 Spring MCP 使用，支持 Claude Code、Codex、Copilot CLI 等。

Skill 库

spring-boot-skills

按 Spring Boot 3 和 4 分成两套 Skill，包括 Spring AI 集成、用 Java SDK 写 MCP Server、AI 可观测等，直接复制到 .claude/skills/ 就能用。

Skill 库

awesome-java-ai

Java AI 项目的精选列表。

Skill 库

代码质量、测试、迁移 6

OpenRewrite

（Moderne 维护） 确定性的自动重构引擎，用现成的"配方"做框架迁移（如 Spring Boot 升级、javax 迁到 jakarta）和安全修复，提供 Maven/Gradle 插件。很适合和 AI 搭配：先用 OpenRewrite 做规则能覆盖的部分，剩下的交给 AI。

Amazon Q Developer 代码转换

把 Java 8/11/17 升到 17/21，在本地构建并跑测试，自动修错误，同时升级 Spring、Hibernate、JUnit 等常用库，有 CLI。

Diffblue Cover

自动给 Java 生成和维护单元测试，可以在 PR 上用 GitHub Action 跑。商业产品。

SonarQube AI CodeFix

针对扫描发现的问题用 LLM 给出修复建议，可以选 Sonar 托管、Azure OpenAI、Bedrock 或自托管模型。

CodeRabbit

AI 代码审查，自动给 PR 写审查意见。

Greptile

理解整个代码库的 AI 审查工具，支持 PR 审查和代码库问答。

运维和可观测 5

K8sGPT

扫描 K8s 集群，用 AI 以大白话解释问题，支持 OpenAI、Bedrock、Gemini 和本地模型。

HolmesGPT

CNCF 沙箱项目，是一个 SRE Agent，能接 Prometheus、Grafana、K8s、告警平台查根因；Operator 模式可以 7×24 小时巡检。

Arthas MCP

同第 2 节，让 AI 做 JVM 级诊断。

SkyWalking MCP

同第 2 节，让 AI 查 APM 数据。

OpenTelemetry GenAI 语义约定

定义 LLM 调用和 MCP 调用的链路与指标标准，Java 应用接 AI 后可以按这套标准做监控。

JVM 平台本身跟 AI 相关 6

Vector API（JEP 529）

SIMD 向量计算 API，JDK 26 里还在孵化；Java 本地推理和向量检索靠它提速。

Project Babylon

OpenJDK 的"代码反射"项目，让程序能分析和转换 Java 代码，目标之一是把 Java 代码编译成 GPU 内核或 ML 模型。

TornadoVM

把 Java 字节码即时编译到 CUDA、OpenCL、Metal 上，在 GPU 上跑；基于它的 jitllm 可以用纯 Java 做 LLM 推理，并且是 LangChain4j/Quarkus 的 GPU 推理引擎。

GraalPy

在 Java 里嵌入 Python 3，可以直接调用 Python 的 AI 库，支持 Maven/Gradle。

Jlama

纯 Java 写的本地 LLM 推理引擎，用 Vector API 加速；据 AI4JVM 说已经不再积极维护。

DJL（Deep Java Library）

AWS 开源的深度学习框架，不绑定引擎，支持 PyTorch、TensorFlow、ONNX Runtime，适合在 Java 服务里直接跑 Embedding 或分类模型。
