🚀 最值得上手
1. jfr-mcp（Jafar）
上手成本最低：JBang 一行装好，拿一份现成的 JFR 录制让 AI 跑一遍诊断，就能看到它怎么用 USE 和线程状态分析定位锁竞争、GC 和 CPU 热点。对日常排障有用，也正好帮你复习面试常考的 JVM 调优思路。

Java 应用接 AI 的框架 3

Koog（JetBrains）

JetBrains 开源的 JVM Agent 框架（Kotlin 写成，1.0 起重做了 Java 互操作层），用图 DSL 编排可预测、可容错的 Agent。8 月 28 日的 1.2.0 加了 Agent Skills 支持，9 月 24 日发布 1.3.0，内置各家最新模型定义，修了 Google 缓存 token 统计。

Agent 框架新版本

AgentScope Java

阿里系的分布式、长时运行 Agent 框架，7 月 2.0 GA。10 月 8 日发布 2.0.4（OpenAI Responses API、按次运行控制、工具与 Skill 隔离、钉钉/个人微信渠道）和 2.1.0-BETA1（AgentScope Service 提供 Docker、Helm 部署包）。上一期只在 AI4JVM 里顺带提过。

Agent 框架新版本

LangChain4j 1.21 / 1.22（重要更新）

上一期推荐过，这次是重要更新：10 月 2 日的 1.21.0 推出实验性 Decision Models，用一次调用拿到分类、路由、打分的概率答案，适合做模型路由、RAG 重排和护栏，还集成了 GPULlama3.java 的继任者 jitLLM；10 月 8 日的 1.22.0 加了 OpenAI Decisions API、Bedrock 批量推理和 Anthropic 自动提示缓存。

重要更新

Agent 协议和 MCP 开发 2

A2A Java SDK

Agent 间通信协议 A2A 的官方 Java SDK（Java 17+，支持协议 1.0 和 0.3），让你的 Java 服务能作为 Agent 被其他 Agent 调用。北京时间 9 月 29 日凌晨发布 1.4.0.Final，多租户 @Tenant 注解挪了包（升级要改 import），SSE 解析可配置。（发布说明）

协议新版本

Quarkus MCP Server

Quarkiverse 的 MCP 服务端扩展，用注解把 Quarkus 里的方法暴露成 MCP 工具、资源和提示词。10 月 8 日发布 2.0.3 修了请求上下文清理等问题；开发中的 2.1 会加 MCP Tasks 异步任务和协议扩展。（发布说明）

MCP新版本

代码质量、测试、迁移 2

Moderne MCP Server

Moderne CLI 自带的本地 MCP 服务（实验性），给 Claude Code、Cursor、Copilot、Codex 等提供基于语义树的代码搜索、全库重命名和 OpenRewrite 配方执行，一条 mod config agent-tools install 装好。官方测试里一次 Java 25 迁移从 6100 多万 token 只完成四分之一，降到约 3 万 token 全部完成。（官方博客，10 月 7 日更新）

迁移MCP

Testcontainers Ollama 模块

在 JUnit 测试里用容器拉起一个真实的 Ollama 本地模型，拿 getEndpoint() 直接喂给 LangChain4j 或 Spring AI，让 AI 功能的集成测试可重复、不花 API 钱。成熟工具，值得放进 AI 项目的测试基线。

测试

运维和 JVM 诊断 2

jfr-mcp（Jafar）

把 JFR 飞行记录交给 AI 分析的 MCP 服务，13 个工具，包括自动诊断、USE 方法、线程状态分析、热点方法、火焰图和异常聚合；用 JBang 一行命令就能跑。只分析录好的 .jfr 文件，不能实时 attach。（作者介绍文章）

JVM性能

kagent

在 Kubernetes 里运行 AI Agent 做运维的框架。北京时间 10 月 22 日凌晨刚发 v1.0.0-alpha17；1.0 线和 0.10.x 不兼容，要全新部署，生产环境先继续用 0.10.x。
