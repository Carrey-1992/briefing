Java × AI 工具推荐

2026-11-16 周一 · 10 条 · 已读 0
🚀 最值得上手
1. isx（Incus Spawn）
你已经在用 AI 编程助手，isx 能在 Mac 上用 Homebrew 或 JBang 装好，给智能体一台不含密钥的一次性 Linux 工作站，避免它碰到本机的密钥和仓库。本周刚有 Quarkus Insights 介绍，v0.5.2 又补上了 MCP 注册和 OpenCode，正好用来安全地让智能体编译和测试 Java 项目。

Java 接 AI 的框架 3

Quarkus LangChain4j 1.15.1 / 2.0.0.Beta4（重要更新）

Quarkus 的 LangChain4j 扩展，第 4 期推荐过 2.0.0.Beta2 / 1.15.0.CR2。11-12（北京时间）同日发布：@Tool 方法支持 Optional 和递归参数类型，AI 服务返回结果会保留模型响应元数据，Vertex AI Gemini 支持 Model Armor，并补充了 MCP 2026-07-28 协议测试；仓库还新增了 AGENTS.md 和给编程智能体用的 Quarkus skills。2.0.0.Beta4 已跟上 Quarkus 4.0.0.CR1。

框架Quarkus更新 11-12

Micronaut LangChain4j 2.4.0

Micronaut 与 LangChain4j 的官方集成。11-11（北京时间）发布的 2.4.0 让 AI 服务和工具不再需要 @AllowsReflection，结构化输出改用 Micronaut JSON Schema；可把 MCP 客户端工具接到 AI 服务，并新增监督者智能体、模型监听与 Micrometer 指标、Google Gen AI，以及 Milvus/Weaviate 存储和原生镜像支持。

框架Micronaut更新 11-11

AgentScope Java 2.0.5（重要更新）

阿里开源的 Java 智能体框架，第 1 期推荐过。11-14（北京时间）发布的 2.0.5 是维护版：加固了状态持久化、取消、上下文压缩和沙箱，@Tool(strict = true) 会递归拒绝未声明参数，Anthropic 默认模型改为 claude-sonnet-5-5。注意：已有的 PostgreSQL/H2/MySQL 表需手动迁移，文件队列格式也变了，要先升级消费端。

框架智能体更新 11-14

MCP 开发 1

MCP Java SDK 2.2.0-M2（重要更新）

MCP 官方 Java SDK，第 1、2 期推荐过 2.1.0。11-14（北京时间）发布的 2.2.0-M2 面向 2026-07-28「modern」服务端预览：会强制校验客户端必选能力和 SEP-2243 的 Mcp-Param 请求头，McpTransportContext 新增 putAll(Map)，并补了官方文档。find 仓库方法改为返回 handler，属于不兼容变更；仍是里程碑预览，写新版服务端的可以先跟上试用。

MCPSDK更新 11-14

AI 编程助手与沙箱 1

isx（Incus Spawn）v0.5.2

Quarkus 早期贡献者 Sanne Grinovero 做的本地沙箱（官网 isx.run），给 Claude Code 等编程智能体分配一台不含密钥的一次性 Linux 工作站，凭证由宿主机代理注入，也可用 JetBrains Gateway 连进去。11-09 的 Quarkus Insights #267 做了介绍，11-14（北京时间）的 v0.5.2 把 OpenCode 列为内置智能体，并支持一键把 isx 注册为 MCP 服务器；可用 Homebrew、JBang 或官方脚本安装。

沙箱编程助手更新 11-14

Java 平台 1

Quarkus 4.0.0.CR1

Quarkus 4 的首个候选版，11-12（北京时间）发布：新增优雅停机 API、quarkus dev --remote，并用 SmallRye Config 支持 Spring 的 @ConfigurationProperties，同时继续去掉各扩展的字节码 recorder；基线是 Java 21，适合开始做迁移测试。另外，3.33 LTS 在 11-10（北京时间）发布了 3.33.4.2 紧急安全更新，修复管理接口授权绕过、Jackson 多态类型校验绕过和 Brotli4J 堆越界写可导致远程代码执行，用 3.33 LTS 的建议尽快升级。

Quarkus安全更新 11-12

运维与可观测性 3

Quarkus AI RCA

用大模型做分布式故障根因分析的开源工具，基于 Quarkus 和 LangChain4j，通过 MCP 连接已有的 Grafana LGTM（Tempo / Loki / Prometheus），把关联的链路、日志和指标交给模型，产出含根因、严重程度和修复建议的报告。11-10（北京时间）Quarkus 官方博客介绍：可下载 Maven Central 上的 uber-jar 直接跑，开发模式也能用 Dev Services 自动拉起 LGTM 试用。

运维可观测性MCP

kagent 1.0.0 / 1.0.1（重要更新）

在 Kubernetes 里运行 AI 智能体的开源框架（CNCF），第 1、4 期推荐过候选版。11-10（北京时间）发布 1.0.0：智能体改跑在 Agent Substrate 上，用 gVisor 或微虚拟机做沙箱，空闲会话会挂起以释放算力，模型密钥和 MCP 凭证只在出口网关注入；可接入自带运行时、Claude、Codex 或符合 A2A 约定的容器。11-12 的 1.0.1 改进了安装和首次创建智能体的流程。从 0.x 升级是新 API，需要重新安装。

运维Kubernetes更新 11-10

Grafana MCP v2.3.0（重要更新）

Grafana 官方 MCP 服务器，第 1、5 期推荐过。11-11（北京时间）发布的 v2.3.0 新增 Elasticsearch 面板查询、精简日志字段，以及把最近 30 天的活跃 IRM 事件暴露成 MCP 资源；并修复了 v2.2.0 中经 query_prometheus 跑 LogQL 指标查询时，可能绕过 Loki 强制匹配器的问题。

MCP监控更新 11-11

JVM 平台 1

JEP 546：ZGC 自适应堆大小（JDK 28）

JDK 28 的 ZGC 增强：按负载和宿主机资源自动调整堆大小，在 CPU 开销和内存占用之间取得平衡，官方目标是达到接近手动调优的吞吐和延迟。11-14（北京时间）的 Inside Java Newscast #117 介绍该 JEP 状态已是 Integrated；容器里跑 Java 服务、常为 -Xmx 发愁的团队值得关注。
