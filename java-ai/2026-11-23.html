Java 接 AI 的框架 4

Spring AI 2.1.0 GA（重要更新）

Spring 官方 AI 框架，第 2、5 期推荐过 2.1.0-RC1 / RC2。11-20（北京时间）正式发布，基于 Spring Boot 4.2，含 430 余次提交、86 位贡献者：支持 MCP 2026-07-28（基于 MCP Java SDK 2.2.0），新增 Decision Models，Session API（含记忆压缩与召回）取代 ChatMemory，并支持 OpenAI Responses API。同期发布的 2.0.3 与 2.1.0 都修复了 13 个 CVE；新项目 Spring AI Agent 计划 12 月初开始孵化。

框架Spring更新 11-20

LangChain4j 1.24.0（重要更新）

最常用的 JVM LLM 库，第 1、3 期推荐过。11-18（北京时间）发布的 1.24.0 为声明式智能体补了辅助对象和完整 CDI 支持，新增 Decision Scheduler 模式，以及 langchain4j-test（可在测试里捕获 AI Service 行为、使用公开模型 mock）；Google Gen AI 侧加上了面向 Gemini Decision API 的 DecisionModel。不兼容变更：已下线的 OpenAI 模型常量被移除，需改用当前常量或直接传模型名字符串。

框架更新 11-18

Google ADK for Java 1.15.0（重要更新）

Google 开源的代码优先智能体工具包，第 2、5 期推荐过。11-18（北京时间）的 1.15.0 为工作流新增带类型端口的 FunctionNode，以及用于路由的 ClassifierNode / LlmClassifier；步骤可请人审批、向用户补问输入，Dev UI 还能展示工作流图。Claude 模型能力已与 ADK Python 对齐，方便在 Java 里编排带人工确认的工作流。

框架智能体更新 11-18

Quarkus LangChain4j 2.0.0.CR1（重要更新）

Quarkus 的 LangChain4j 扩展，第 4、6 期推荐过 2.0.0.Beta 与 1.15.1。11-21（北京时间）发布首个候选版：已移植到 Quarkus 4，示例和测试基线为 Java 21，并升级到 LangChain4j 1.24.0；新增上下文压缩扩展及配套评测，流式 AI 服务可并发执行工具，Dev UI 聊天页支持附加图片。仍是预览，Quarkus 4.0 正式版在官方发布页上计划于 11-25 推出。

框架Quarkus更新 11-21

MCP 开发 1

MCP Java SDK 2.2.0（重要更新）

MCP 官方 Java SDK，上期刚推荐过 2.2.0-M2。11-16（北京时间）下午发布正式版：在 io.modelcontextprotocol.modern 中提供面向 2026-07-28 规范的无状态服务端和客户端（与旧版并存），并配了新文档。现代 API 在 3.0 之前仍可能随小版本调整；若已试用里程碑，需注意 find 返回 handler、McpParamHeaders 改为 McpHeaders 等不兼容变更。

MCPSDK更新 11-16

代码质量与 MCP 1

SonarQube MCP Server 1.33.0（重要更新）

Sonar 官方 MCP 服务器，第 3、5 期推荐过。11-20（北京时间）的 1.33.0 让智能体按调用者权限读取各语言的架构覆盖率，以及偏差、缺陷和坏味道计数；启用 architecture 工具集时，会在 initialize 的指令里提醒先调用 architecture_get、改完再校验新依赖。同时升级到 MCP Java SDK 2.2.0，并把工具 schema 做成可重复序列化，减少客户端缓存失效和多余 token。

MCP代码质量更新 11-20

AI 编程助手与沙箱 1

isx（Incus Spawn）v0.5.3（重要更新）

给编程智能体分配不含密钥的一次性 Linux 工作站，上期刚推荐过 v0.5.2。11-18（北京时间）的 v0.5.3 新增 isx overview，可查看各实例的 token、分支、PR 和收工说明，销毁前会提示未提交改动；工具只要声明一次 MCP，Claude Code、Codex、OpenCode 等智能体都能用，其中 jasolo 可让智能体阅读依赖的 Java 源码。Maven/Gradle/npm 遇到 429 时会改走代理缓存，降低构建被限流打断的概率。

沙箱编程助手更新 11-18

运维与可观测性 1

HolmesGPT 0.47.0（重要更新）

CNCF 沙箱的 SRE 智能体，第 1、5 期推荐过。11-22（北京时间）的 0.47.0 把 Kubernetes MCP 插件放到 Holmes Pod 内，用挂载的 kubeconfig 运行，并默认把 kubernetes/logs 暴露给其他集群；判断 Pod 失败原因前会先查看告警历史。还补充了在 OpenShift OAuth 和 PingFederate 下为 Kubernetes MCP 做按用户鉴权的文档。

运维Kubernetes更新 11-22

Java 平台 1

Spring Boot 4.2.0

Spring Boot 的最新次版本，11-19 官方博客宣布、北京时间 11-20 已可从 Maven Central 获取（发布说明）。亮点包括 AMQP 1.0（通用及针对 RabbitMQ）、可选的 OpenTelemetry 语义约定、可执行 jar 启动更快，以及 Cloud Native Buildpacks 默认基于 Ubuntu 26.04。RestTemplate / TestRestTemplate 和 Apache Pulsar 支持已弃用，分别改用 RestClient / RestTestClient；Spring AI 2.1 正是基于这个版本构建的。

Spring Boot更新 11-20

JVM 平台 1

JEP 547：Lazy Constants（JDK 28 第四次预览）

为延迟初始化的不可变数据提供 API：由 JVM 当作真正的常量做优化，性能接近 final 字段，但初始化时机更灵活，有助于缩短启动时间。11-20（北京时间）Inside Java 宣布该 JEP 已 Targeted 到 JDK 28，相对 JDK 27 的 JEP 531 没有 API 改动，仍是预览。
