Java × AI 工具推荐 · 第 2 期

2026-10-26 周一 · 8 条 · 已读 0
🚀 最值得上手
1. Spring AI 2.1.0-RC1
RC 意味着 API 基本定型，离正式版不远。工具调用确认正好解决「AI 自动调了有副作用的接口」这个上线顾虑，会话记忆压缩能控住长对话的 token 成本，在现有 Spring Boot 项目里升级一下就能试，投入小、收获直接。
ℹ️ 本期 8 项，日期均为北京时间；标「重要更新」的是之前清单里出现过、这次有新版本的。
全部Java 应用接 AI 的框架MCP 开发和 MCP 服务器JVM 平台和 AI# Spring# 新版本# Agent# MCP# 编码助手# 协作# 数据库# GPU

Java 应用接 AI 的框架 3

Spring AI 2.1.0-RC1（重要更新）

10 月 23 日晚发布（同时出了 2.0.2）。新增工具调用确认（执行工具前可以先让人确认）、带按轮次压缩的会话记忆（旧的 ChatMemory 标记废弃），OpenAI 和 DeepSeek 模型迁到 message parts，TokenTextSplitter 支持重叠切块。升级前看升级说明。

Spring新版本

LangGraph4j 1.9.7

Java 版的 LangGraph，用有状态的图来编排多步 Agent，带检查点，可以接 LangChain4j 和 Spring AI。10 月 25 日发布的 1.9.7 让 LangChain4j 执行器也能挂节点和边的钩子，可以在长耗时工具前中断、到图外执行后再注入结果续跑。

Agent新版本

Google ADK for Java 1.13.0（重要更新）

10 月 21 日发布，新增工作流图：可以建图的边、跑整张图或单个节点；接 LangChain4j 时 modelName 变成可选；Dev 服务默认只允许同源请求并拦截 DNS 重绑定，把 ADK 工具转成 MCP 工具时的 JSON Schema 也修正了。

Agent新版本

MCP 开发和 MCP 服务器 4

MCP Java SDK 2.1.0（重要更新）

10 月 16 日发布。支持按条件过滤工具列表，基于 HttpClient 的传输层改成 Publisher 实现，Streamable HTTP 服务端加了会话清理和保活，并去掉了 2024-11-05 旧协议；还修了 STDIO 发消息的线程安全问题。自己写 MCP 服务端的话值得升级。

MCP新版本

Serena 2.x

给编程 Agent 用的「IDE」：通过 MCP 提供符号级的代码检索、编辑和重构，底层走语言服务器，支持 Java、Kotlin 等语言，大项目里比按行号或文本搜索更省 token、更准。10 月 13 日发布 2.0（改为 GPL 许可，加了 REPL 式接口），10 月 20 日 2.1.0 补了不受信项目的安全限制。

编码助手MCP

GitHub MCP Server 2.0.3

GitHub 官方 MCP，让 Agent 读仓库、管 Issue 和 PR、查 Actions。10 月 21 日的 2.0.3 给 list_label 加了分页，超过 1 MB 的文件改返回资源链接，并升级 Go 版本以应对被攻破 CA 的问题。

MCP协作

MCP Toolbox for Databases 1.15.0

Google 开源的数据库 MCP 服务器，支持 PostgreSQL、MySQL、SQL Server、Redis、Spanner、AlloyDB 等，用配置文件定义工具，连接池和鉴权都替你管好。10 月 23 日发布 1.15.0，给各协议版本补上了 MCP Apps UI 支持。

MCP数据库

JVM 平台和 AI 1

TornadoVM 7.3（重要更新）

让 Java 代码跑在 GPU 上的框架。10 月 14 日发布 7.3.0（15 日跟进 7.3.1）：Metal 后端接入 Apple MLX 并改了命令缓冲提交方式，官方称 LLM 解码快了 6 倍；新增 tornado-nccl 做多 GPU 集合通信，CUDA 下每块 GPU 有独立上下文。
