🚀 最值得上手

新的 langchain4j-test 模块解决了 AI 功能最难的一环：怎么写单元测试。可以用 LLM 评委给回答打分、对发出的聊天请求做断言，直接塞进现有 JUnit 流水线；如果你已经在用 LangChain4j，升级一个版本就能给 AI 功能补上回归测试。

Java 应用接 AI 的框架 2

LangChain4j 1.23.0（重要更新）

10 月 29 日凌晨发布。新增 langchain4j-test 模块，可以用 LLM 当评委对聊天请求写断言；新增决策 Agent 和「置信度级联」Agent 模式、Ollama 决策模型；AiServiceInvocationSummaryEvent 把一次 AI Service 调用的所有事件汇总，方便做可观测性；还给 pgvector、MariaDB 的元数据过滤改成参数绑定，并升级 Jackson 修复 DoS 漏洞。

LangChain4j测试新版本

Embabel Agent 1.5.4（重要更新）

Spring 之父 Rod Johnson 团队做的 JVM Agent 框架。10 月 28 日发布 1.5.4：新增分类和决策服务（可以用 LLM 实现，也能从配置注册），OpenAI 兼容模型改走 Responses API，支持 Claude 5.x 原生 thinking，并修了 AnthropicModelFactory 的内存泄漏。

AgentSpring新版本

代码质量和测试 2

SonarQube MCP Server 1.30

SonarSource 官方的 MCP 服务器，让编程 Agent 直接查 SonarQube 的问题、质量门和覆盖率，改完代码顺手把质量问题一起修掉。10 月 24 日发布 1.30：SonarQube Cloud 托管版支持完整 OAuth，新增 list_organizations，单次调用可指定组织；还修了初始化失败时阻止 JVM 正常退出、数字参数被丢弃等问题。

MCP代码质量

Playwright MCP 0.0.83

微软官方的浏览器自动化 MCP，Agent 通过页面的可访问性快照来点按、填表和截图，适合让 AI 帮你回归测试 Spring Boot 后端配套的 Web 页面、复现前端 bug。9 月 29 日发布的 0.0.83 修了页面加载时弹窗导致超时、下载时关浏览器会崩等问题，Docker 镜像也会清理残留的浏览器进程。

MCP测试

MCP 运行和 LLM 可观测性 2

Docker MCP Gateway

Docker 的 docker mcp 命令行插件：每个 MCP 服务器跑在隔离的容器里，所有客户端（Cursor、Claude Code、VS Code 等）连同一个网关，密钥交给 Docker 管理，还能按 profile 分组、给工具设白名单、推到 OCI 仓库分享。团队统一管理 MCP 配置很省事。最新是 10 月 27 日的 v0.44.3 预发布版（未附更新说明）。

MCP安全

Langfuse v4.71

开源的 LLM 可观测性平台（追踪、评测、提示词管理），可自建。官方有 Spring AI 接入指南，通过 Micrometer 和 OpenTelemetry 把每次模型调用的提示词、输出和 token 用量发过去。10 月 27 日发布 v4.71.0，主要增强 AI 网关记录（模型、密钥归属、上游错误）和 Topics 视图。

可观测性运维

JVM 平台和 AI 1

DJL 0.39.0（重要更新）

亚马逊开源的 Java 深度学习库，在 JVM 里直接跑 PyTorch、ONNX 等模型推理。10 月 20 日发布 0.39.0，以安全加固为主：请求里带的图片 URL 和 synsetUrl 只允许 data: 和 http(s)，各引擎的缓冲区大小计算加了溢出检查，加载内置模型类改为需要显式开启。
