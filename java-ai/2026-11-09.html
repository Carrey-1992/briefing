Java × AI 工具推荐

2026-11-09 周一 · 12 条 · 已读 0
🚀 最值得上手
1. IntelliJ IDEA 2026.3（JetBrains Air）
你每天都在 IDEA 里写 Java，升级就能用，零迁移成本。Air 让你在同一个 IDE 里并行跑多个编程智能体、按会话看 diff 和回滚，智能体还能借助 IDE 的索引、检查和调试器干活，比在终端里裸跑更可控，正好用来体验和比较各家 AI 编程助手。

Java 接 AI 的框架 4

Spring AI 2.1.0-RC2（重要更新）

Spring 官方的 AI 集成框架。11-06（北京时间）发布的 2.1.0-RC2 新增 DecisionModel API（含 OllamaDecisionModel、SystemOneDecisionModel），可用于工具检索（DecisionToolIndex）和 RAG 文档后处理；服务端支持 MCP 2026-07-28 新版协议，工具调用参数支持流式增量，Chroma、MariaDB、MongoDB Atlas、Neo4j 等向量库补上了 upsert。2.1 GA 前值得拿 RC2 做一轮回归。

框架Spring AI更新 11-06

Google ADK for Java 1.14.0（重要更新）

Google 的 Java 智能体开发套件，第 1、3 期推荐过。11-02（北京时间）发布的 1.14.0 加了 ADK 与 Spring AI 的双向转换和 Spring Boot 聊天示例，工作流能暂停等用户输入、再从会话事件恢复，还能把工具当工作流节点、对列表逐项运行节点，并移植了 DebugLoggingPlugin。

框架智能体更新 11-02

A2A Java SDK 1.5.0.Final（重要更新）

Agent2Agent（智能体互通）协议的 Java SDK，第 2 期推荐过。11-03（北京时间）发布的 1.5.0.Final 给 OpenTelemetry 集成补了流式 span 生命周期、操作指标、推送通知链路追踪和 trace 上下文传播，还修了 JSON-RPC、REST 的几个边界问题；服务端校验做了集中重构（有不兼容变更）。

框架A2A可观测性

LangGraph4j 1.9.8 / 1.9.9（重要更新）

LangGraph 的 Java 实现，用图来编排有状态的多步智能体，第 3 期推荐过 1.9.7。11-04 的 1.9.8 新增按值相等删除列表元素的 RemoveEquals、CompiledGraph.invokeSync()；11-08（均为北京时间）的 1.9.9 新增 filesystem-saver 模块，可把检查点存到文件系统，并修复并行分支丢结果的问题。

框架智能体

IDE 与 AI 编程助手 1

IntelliJ IDEA 2026.3（JetBrains Air）

IDEA 新版（GitHub 发布标签时间为北京时间 11-05）内置 JetBrains Air：在 IDE 里并行跑和审查 Claude、Codex、Copilot、Junie、Cursor 等编程智能体，可本地、云端或临时 worktree 运行，改动可看 diff 和回滚；智能体能通过 IDE 的 MCP 服务器用上索引、检查和调试能力（还有 ij-debugger Skill）。同时支持 Java 28、Hibernate 8。

IDE智能体更新 11-05

MCP 服务器 3

Grafana MCP v2.2.0（重要更新）

Grafana 官方 MCP 服务器，第 1 期推荐过。11-02（北京时间）发布的 v2.2.0 新增 CloudWatch Logs Insights 查询工具、把数据源暴露成 MCP 资源（Claude Code 里可用 @ 直接附上），还加了可选的 Prometheus 查询护栏，防止智能体发出时间范围过大的查询；注意 query_prometheus 不再自动弹出图表 App（不兼容变更）。

MCP监控

SonarQube MCP Server 1.31（重要更新）

SonarSource 官方 MCP 服务器，让 AI 助手直接查质量问题和规则，第 4 期推荐过 1.30。11-02（北京时间）发布的 1.31 新增可选的 architecture 工具集，智能体能读取和设置项目的目标架构；修复了 HTTP 传输下工具调用无限挂起的问题，并升级到 MCP Java SDK 2.1.0。

MCP代码质量

Kubernetes MCP Server v0.1.x（重要更新）

containers 组织的 Kubernetes/OpenShift MCP 服务器（Go 原生，不依赖 kubectl），第 1 期推荐过。10-30 发布 v0.1.0，统计在途 MCP 请求数、补可观测性工具集评测；11-05（均为北京时间）的 v0.1.2 新增 api_resources_list 工具，智能体可以查 CRD 的 apiVersion，少写错资源版本。

MCPKubernetes

代码迁移 1

OpenRewrite rewrite-migrate-java v3.53 / v3.54（重要更新）

OpenRewrite 的 Java 迁移配方库（升级 JDK、Jakarta、去 Guava 等），OpenRewrite 第 1 期推荐过。11-06 的 v3.53 大幅改进去 Guava 配方（如 Strings.isNullOrEmpty、Files.toString、Lists.newArrayList 的替换，以及无法等价替换时保留原写法），11-07（均为北京时间）的 v3.54 让 Jakarta Faces 迁移保留页面 XML。

迁移代码质量

运维与可观测性 2

Arconia v0.32.0

给 Spring Boot 补开发服务（类似 Quarkus Dev Services）、多租户和 OpenTelemetry 能力的框架，对 Spring AI 应用尤其友好。11-03（北京时间）发布的 v0.32.0 新增 Langfuse 开发服务和 Langfuse AI 语义约定、内置 Spring AI 可观测性 Grafana 仪表盘，并完善 OpenInference、LangSmith、OpenLIT 的埋点约定；本地起 LLM 可观测栈几乎零配置。

可观测性Spring Boot更新 11-03

HolmesGPT 0.46.0（重要更新）

CNCF 的 AI 故障排查智能体，能接 Prometheus、K8s、日志等排查告警，第 1 期推荐过。11-04（北京时间）发布的 0.46.0 支持给 MCP 服务器配置 allowed_tools 只加载部分工具，告警可推送到 webhook，遇到 LLM 限流、过载和 503 会退避重试，不再直接失败。

运维Kubernetes

JVM 平台 1

TornadoVM 8.1.0（重要更新）

让 Java 代码跑在 GPU/FPGA 上的 JVM 插件，常用于 Java 本地推理加速，第 1、3 期推荐过。11-06（北京时间）发布的 8.1.0 把 OpenCL 和 Metal 驱动发布到 Maven Central、无需安装 SDK 也能运行，新增统一内存上原地使用主机数组、异步初始化设备等 API；SDK 包支持 JDK 21/25/26/27。
