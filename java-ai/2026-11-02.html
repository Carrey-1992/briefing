Java × AI 工具推荐

2026-11-02 周一 · 8 条 · 已读 0
🚀 最值得上手
1. Spring AI Agent Utils
它把 Claude Code 那一套文件、Shell、Todo、Skill、子智能体能力原样搬进了 Spring AI，还带 code-agent-demo 等示例。跑一遍示例就能看懂编程智能体内部怎么组织工具和 Skill，对你理解 AI 编程助手的原理、在 Java 项目里落地智能体，以及面试聊 Agent 设计都很有用。

Java 接 AI 的框架 3

Quarkus LangChain4j 2.0.0.Beta2 / 1.15.0.CR2（重要更新）

Quarkus 官方的 LangChain4j 集成。11-01（北京时间）同时发布 2.0.0.Beta2 和 1.15.0.CR2：修复 MongoDB 聊天记忆没按 BSON 文档存储的问题，补了 Amazon Bedrock 接入指南，MCP 客户端测试也拆成了新旧两套协议。在用 Quarkus 做 AI 服务的话，可以先用 CR2 做回归测试。

框架Quarkus更新 11-01

Solon AI v4.1.1

国产 Solon 生态里的 Java AI 应用框架，覆盖 LLM 工具调用、Skill、RAG、MCP 和 ReAct/Team 智能体，还支持 JDK 8。10-01（北京时间）发布的 v4.1.1 把流式事件归并收拢到 ChatAccumulator，ChatResponse 改成只读的最终结果，并新增工具调用、引用等取值方法。这版有不兼容变更，升级前先看 发布说明。

框架国产

Spring AI Agent Utils v0.13.0

Spring AI 社区项目，参照 Claude Code 把文件读写、Shell、网页访问、TodoWrite、Agent Skills、子智能体（含 A2A 远程子智能体）和长期记忆做成了 Spring AI 工具。10-04（北京时间）发布的 v0.13.0 支持用 SkillsTool.Builder 以代码方式注册 Skill，同一 classpath 前缀下多个 SkillsJar 的 Skill 也能合并加载。想在自己的 Spring 应用里搭一个编程智能体，用它可以少写很多胶水代码。

框架Spring AI智能体

RAG 与文档处理 1

Docling Java 0.7.1

Docling 文档解析的 Java API，包括 docling-core、Docling Serve 客户端，还有 Testcontainers 模块，能把 PDF 等文档转成结构化内容给 RAG 用。10-23（北京时间）发布的 0.7.1 新增 PDF 标题层级相关选项；0.7.0 则支持给异步调用传自定义 Executor。

RAG文档解析

测试与开发工具 2

Playwright for Java v1.64.0

Playwright 的 Java 版浏览器自动化和 E2E 测试库。10-22（北京时间）发布的 v1.64.0 新增 page.webmcp()/frame.webmcp()，能列出并调用页面通过实验性 WebMCP 浏览器 API 注册的工具。给 Web 应用加 AI 工具接口时，可以直接在 JUnit 里测试这些工具。

测试WebMCP

JBang 0.143.0

不用建 Maven/Gradle 工程，就能直接运行单文件 Java 脚本和 Maven 坐标，很多 Java 写的 MCP 服务器和 AI 小工具都靠它一行命令启动。10-31（北京时间）发布的 0.143.0 统一了别名指定版本的写法，现在一律是 jbang mytool:1.5.0@mycatalog，不管别名背后是 Maven 制品还是 Git 地址都一样。

运维与可观测性 2

kagent v1.0.0-rc1（重要更新）

跑在 Kubernetes 里的 AI 智能体框架（CNCF 项目），第 2 期推荐过。10-31（北京时间）发布了 1.0.0 的第一个候选版，加强了认证体系：区分人类和机器身份、网关 Actor JWT 凭证、按所有者做资源 RBAC，CLI 的对话界面也改进了。

运维Kubernetes

K8sGPT v0.4.41（重要更新）

用 AI 解释 Kubernetes 集群故障的 CLI，第 1 期推荐过。10-20 的 v0.4.41（GitHub 发布时间为北京时间 10-21）新增 Amazon Bedrock 上的 Claude 4.5 和 5.x 模型，本地 Ollama 缺模型时会提示自动拉取，Gateway API、NetworkPolicy、Kyverno 等分析器也修了一批误报和漏报。
