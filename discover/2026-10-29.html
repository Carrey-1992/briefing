日志与检索 6

Elasticsearch / ELK（背景）

Elastic 的搜索与分析引擎，加上 Logstash、Kibana 就是经典的 ELK 日志方案，下面几款大多是拿来对比或替代它的。适合已有 Elastic 生态、需要全文检索和成熟商业支持的团队。AI 集成：官方 mcp-server-elasticsearch 仓库已标注弃用，改为 Elastic 9.2.0+ 自带的 Agent Builder MCP 端点。

搜索ELKMCP 官方

OpenSearch

AWS 主导、Apache 2.0 许可的 Elasticsearch/Kibana 分支，附带 OpenSearch Dashboards。适合想避开 Elastic 许可限制、或用 AWS 托管服务时替代 ELK。AI 集成：有官方 opensearch-project/opensearch-mcp-server-py（MCP 服务器），本地 Agent 可直接接入。

搜索日志MCP 官方

Graylog

集中式日志管理平台，内置采集输入、解析规则（Pipeline）、告警和检索界面，底层存储用 OpenSearch。可替代 Logstash + Kibana 这套组合，适合想要开箱即用的日志中台、少写配置的团队。AI 集成：本次未找到经核实的 MCP 服务器。

日志告警

Grafana Loki

Grafana 的日志聚合系统，只索引标签、不做全文索引，存储成本远低于 ES。适合 Kubernetes 和云原生场景替代 ELK，尤其已在用 Prometheus/Grafana 时。AI 集成：没有单独的 MCP，但官方 grafana/mcp-grafana 支持 Loki 查询。

日志云原生MCP 经 Grafana

Vector

Datadog 维护的 Rust 写的可观测数据管道，负责采集、转换、路由日志和指标。可替代 Logstash、Fluentd 做采集与加工，适合追求高吞吐、低资源占用的场景。AI 集成：未找到。

采集管道Rust

Fluent Bit

CNCF 下的轻量日志与指标采集器，常以 DaemonSet 形式跑在 K8s 每个节点上。可替代 Filebeat、Fluentd 做边缘采集，适合资源紧张的节点和容器环境。AI 集成：未找到。

采集K8sCNCF

BI 与数据看板 4

Metabase

上手最快的开源 BI，业务同事点几下就能出报表和看板，也支持写 SQL。可替代 Tableau、Power BI 的轻量自助分析场景，适合中小团队快速给运营和产品做数据看板。AI 集成：未找到官方 MCP 服务器，GitHub 上有多个社区实现（如 CognitionAI/metabase-mcp-server），使用前需自行评估。

BI自助分析MCP 社区

Apache Superset

Apache 基金会的企业级 BI 与数据探索平台，图表类型多，权限和 SQL Lab 完善。可替代 Tableau、Looker，适合数据量大、需要细粒度权限和多数据源的团队。AI 集成：未找到官方 MCP，有社区实现 aptro/superset-mcp。

BIApacheMCP 社区

Grafana

以时序指标和监控看板见长的可视化平台，可接 Prometheus、Loki、MySQL、ES 等多种数据源。可替代 Kibana 做运维看板，适合监控告警与技术指标展示，而非业务报表。AI 集成：有官方 grafana/mcp-grafana，可查询看板、Prometheus、Loki 等。

看板监控MCP 官方

Redash

以 SQL 查询为核心的轻量看板工具，写好查询就能生成图表并分享。适合会写 SQL 的开发和数据同学替代临时导 Excel，做简单报表。AI 集成：未找到经核实的 MCP 服务器。
