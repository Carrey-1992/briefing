开源工具与中间件发现 · 第 2 期：可观测性与监控（指标、链路、告警）

2026-11-03 周二 · 11 条 · 已读 0
🚀 最值得上手
1. OpenTelemetry Java Agent
对 Java 开发最直接：给本地 Spring Boot 服务加一个 -javaagent，配上 Jaeger 就能马上看到完整调用链，而且是面试常问的行业标准。
2. SigNoz
Docker 一键起，指标、链路、日志一个界面全看到，还有官方 MCP 服务器，可以让本地智能体直接帮你查问题。
3. VictoriaMetrics
了解为什么很多团队用它替代 Prometheus 长期存储，资源占用低，且有官方 MCP。

指标与告警 4

Prometheus

CNCF 毕业的指标监控系统和时序数据库，拉取式采集，用 PromQL 查询，Spring Boot Actuator + Micrometer 可直接暴露指标。对标 Zabbix、Nagios 这类传统监控，适合 K8s 和微服务的指标监控，几乎是行业默认选项。AI 集成：无官方 MCP；官方 grafana/mcp-grafana 带 Prometheus 查询工具，另有社区实现 pab1it0/prometheus-mcp-server。

指标CNCFMCP 经 Grafana

VictoriaMetrics

高性能、低成本的时序数据库和监控方案，兼容 Prometheus 协议和 PromQL（扩展为 MetricsQL）。可替代 Prometheus 做长期存储，或替代 Thanos、Cortex、InfluxDB，适合指标量大、想省内存和磁盘的场景。AI 集成：有官方 VictoriaMetrics/mcp-victoriametrics MCP 服务器。

时序库Prometheus 兼容MCP 官方

Prometheus Alertmanager

Prometheus 生态的告警中心，负责告警去重、分组、静默、抑制，再路由到邮件、Webhook、钉钉/企业微信（经 Webhook）等。对标 Zabbix 告警模块或 PagerDuty 的路由部分，用了 Prometheus 就该配上它，避免告警风暴。AI 集成：无独立 MCP；grafana/mcp-grafana 支持 Alertmanager 数据源（Prometheus Alertmanager、Mimir、Cortex）。

告警MCP 经 Grafana

Uptime Kuma

一个好看易用的自托管可用性监控工具，能探测 HTTP、TCP、Ping、DNS 等，并提供状态页和多渠道通知。对标 UptimeRobot、Pingdom，适合个人项目或小团队快速盯住接口和站点是否在线。AI 集成：未查到。

拨测状态页

链路追踪与 APM 7

OpenTelemetry Java Agent

OpenTelemetry 官方的 Java 自动埋点，挂一个 -javaagent 就能零代码采集 Spring、JDBC、Kafka、HTTP 客户端等的链路、指标和日志。对标 SkyWalking Agent、Pinpoint 或商业 APM 探针，适合想用厂商中立标准、后端随时可换的团队。AI 集成：未查到专用 MCP 服务器。

Java埋点标准

OpenTelemetry Collector

OpenTelemetry 的遥测数据中转站，接收、处理（采样、脱敏、打标签）、再导出到 Jaeger、Prometheus、Loki 等各种后端。可替代各家私有 Agent 和部分 Logstash 角色，适合多种后端并存、需要统一采集管道的场景。AI 集成：未查到。

采集管道CNCF

Jaeger

CNCF 毕业的分布式链路追踪平台，v2 起基于 OpenTelemetry Collector 重构，原生接收 OTLP。对标 Zipkin，适合微服务排查慢调用、看调用链。AI 集成：Jaeger v2 的查询扩展内置 MCP 工具（如 search_traces），最新 v2.22.0 的更新里也有 MCP 相关修复。

链路CNCFMCP 内置

Grafana Tempo

Grafana 的大规模链路追踪后端，只依赖对象存储，成本低，用 TraceQL 查询。对标 Jaeger、Zipkin，适合已在用 Grafana/Loki/Prometheus、想把指标日志链路串起来的团队。AI 集成：官方文档有 MCP 服务器章节，从 2.9 版本起内置 MCP 服务器。

链路GrafanaMCP 内置

Apache SkyWalking

国人主导的 Apache 顶级 APM 项目，Java Agent 自动埋点，提供拓扑图、链路、指标、告警一体化界面。对标 Pinpoint、Zipkin 和商业 APM，在国内 Java 微服务团队里非常常见，适合想要开箱即用 APM 的场景。AI 集成：有官方 apache/skywalking-mcp，可让智能体查询 SkyWalking OAP。

APMJavaMCP 官方

SigNoz

基于 OpenTelemetry 的一体化可观测平台，指标、链路、日志放在一个界面里，底层用 ClickHouse。对标 Datadog、New Relic，适合想用一套开源方案替代多个组件拼装的团队。AI 集成：有官方 SigNoz/signoz-mcp-server，可查询指标、链路、日志、告警和看板。

一体化OpenTelemetryMCP 官方

Grafana Pyroscope

持续性能剖析平台，长期采集 CPU、内存分配、锁等火焰图，能定位到具体代码行，支持 Java（基于 async-profiler）。对标手动跑 async-profiler、JFR 或商业 Profiler，适合排查线上偶发的 CPU 飙高和内存问题。AI 集成：无独立 MCP；grafana/mcp-grafana 带 Pyroscope 工具。
