开源工具与中间件发现 · 第 5 期：缓存与内存数据库

2026-11-23 周一 · 11 条 · 已读 0
🚀 最值得上手
1. Caffeine
加依赖、打开 @EnableCaching，Spring Boot 就能自动配上本地缓存，先搞懂缓存抽象，几乎不用运维。
2. Redis
行业默认的分布式缓存，配上官方 MCP 后本地智能体还能帮你查改数据。
3. Redisson
已经有 Redis 或 Valkey 的话，加一个 Spring Boot Starter 就能试分布式锁和 Spring Cache，Java 项目里立刻用得上。

分布式缓存与 Redis 兼容存储 5

Redis

最常见的内存数据结构和缓存服务器，也常用于会话、排行榜等场景。对标 Memcached 的简单 KV 缓存；Spring Boot 把它列为 Cache 自动配置提供者之一。许可方面，官方文档写明 8 起可选 RSALv2、SSPLv1 或 AGPLv3，7.2 及更早仍是 BSD-3-Clause。AI 集成：有官方 redis/mcp-redis MCP 服务器，本地智能体可直接连 Redis 查改数据；另有面向 Redis Cloud 账号管理的远程 MCP。

缓存RedisMCP 官方

Valkey

Linux Foundation 托管的 BSD-3-Clause 开源键值库，由 2024 年 Redis 变更许可证后的社区分叉而来，可用于缓存、消息队列或作为主库。对标 Redis，适合希望继续使用 BSD 开源协议、并用现有 Redis 客户端接入的场景。AI 集成：未查到 Valkey 项目官方 MCP。

缓存Redis 兼容Linux Foundation

Dragonfly

官方定位为 Redis 和 Memcached 的现代替代，采用多线程架构，文档称已实现 200 多个 Redis 命令。适合想沿用 Redis 协议、又希望单机垂直扩展、少做集群分片的场景。从 v2.1 起以 Dragonfly Enterprise 按 DSAL（源码可用许可，官方说明它不是严格的开源许可）发布，生产环境合计最多 100 个 vCPU 可免费使用，超出需商业许可，开发/测试不限。AI 集成：官方提供面向 Dragonfly Cloud 的托管 MCP；未查到面向自建实例的官方本地 MCP。

缓存Redis 兼容MCP 云端

Memcached

经典的分布式内存对象缓存，协议简单，主要存放 KV 字节数据。对标 Redis 里“只做缓存、不要复杂数据结构”的需求，适合会话或热点对象的简单缓存。AI 集成：未查到 memcached 项目官方 MCP；AWS 实验室仓库中有 memcached-mcp-server，使用前需自行评估。

缓存KV

Apache Kvrocks

Apache 基金会的分布式 KV 数据库，用 RocksDB 做存储引擎并兼容 Redis 协议，官方说明可用任何 Redis 客户端访问，目标是比纯内存的 Redis 更省内存、容量更大。对标 Redis/Valkey 的全内存方案，适合数据量已经大到不想全部放内存、但仍想用 Redis 命令的场景。AI 集成：未查到。

缓存Redis 兼容Apache

Java 本地缓存、客户端与内存数据网格 6

Caffeine

Java 进程内高性能缓存库，设计上借鉴了 Guava Cache 的经验，提供基于大小和过期时间的淘汰等能力。对标 Guava Cache 等本地缓存；Spring Boot 把它列为 Cache 自动配置提供者之一，Quarkus 缓存扩展的默认后端也是它，适合先在应用内做本地缓存，或作为多级缓存的本地层。AI 集成：未查到（检索到的 “Caffeine MCP” 属于同名的 Caffeine AI 产品，与本库无关）。

本地缓存JavaSpring

Hazelcast

Java 编写的分布式内存数据平台，提供 IMap 等分布式结构，也可做缓存和流处理。对标 Redis 这类独立缓存服务，区别是可以嵌入 JVM 或作为集群运行；Spring Boot 也把它列为 Cache 自动配置提供者。Community Edition 以 Apache 2.0 和 Hazelcast Community License 发布，部分能力属于 Enterprise Edition。AI 集成：未查到官方 MCP。

数据网格Java分布式缓存

Infinispan

开源分布式内存数据库（由 Commonhaus Foundation 托管），可嵌入应用或独立部署，并支持 HotRod、REST、Redis、Memcached 协议。对标 Hazelcast、Redis，也是 Spring Boot Cache 自动配置以及 Quarkus 的可选缓存后端之一，适合 JVM 集群里的共享缓存、会话，以及需要查询或向量检索的场景。AI 集成：官方内置 MCP 服务器，可用 CLI 做 stdio 桥接，见用例说明和教程。

数据网格JavaMCP 内置

Apache Ignite

内存优先的分布式 SQL 数据库，官方也将大规模会话管理和缓存列为典型用例。对标 Hazelcast、Infinispan 这类内存网格，适合需要分布式 SQL、跨节点事务，或把缓存和计算放在一起的场景。官网下载页将 Ignite 2（apache/ignite）标为新项目与生产推荐，并提供 Spring Cache / Spring Boot 等扩展；Ignite 3（apache/ignite-3）仍可下载，但社区在 2026 年 10 月注明暂无下一版发布计划。AI 集成：未查到已发布的官方 MCP。

数据网格JavaApache

Redisson

面向 Valkey 与 Redis 的 Java 客户端，在连接之上提供分布式锁、集合、队列等 60 多种对象和服务。对标 Jedis、Lettuce 这类命令级客户端，适合已经在用 Redis/Valkey、又需要分布式锁、Spring Cache、Spring Session 或 JCache 的项目；官方提供 Spring Boot Starter。AI 集成：未查到。

JavaRedis 客户端分布式锁

JetCache

阿里巴巴开源的 Java 缓存框架，提供比 Spring Cache 更强的注解（原生 TTL、LOCAL/REMOTE/BOTH 两级缓存、分布式自动刷新），并支持 Spring Boot。对标 Spring Cache 抽象，底层可接 Caffeine 本地缓存和 Redis 远程缓存，适合国内常见的多级缓存场景。AI 集成：未查到。
