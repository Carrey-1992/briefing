开源工具与中间件发现 · 第 4 期：API 网关与服务治理

2026-11-16 周一 · 10 条 · 已读 0
🚀 最值得上手
1. Spring Cloud Gateway
Java 开发者加一个 starter 就能在熟悉的 Spring Boot 里写路由和过滤器，先搞懂网关概念，再看独立网关会轻松很多。
2. Sentinel
国内同事讨论限流熔断时经常提到，接上 Spring Cloud 适配再打开 Dashboard，能立刻看到规则和实时指标。
3. Apache APISIX
Docker 一条命令就能起一个独立网关，加上 api7/apisix-mcp 后本地智能体还能帮你查路由。

API 网关 6

Apache APISIX

基于 Nginx 和 etcd 的动态高性能 API 网关，配置可热更新，也能当 Kubernetes Ingress，对标 Kong 和传统 Nginx 反向代理。适合微服务里要动态路由、认证、限流和插件扩展，并且不想重启网关就能改配置的场景。AI 集成：官方也把它定位为 AI 网关（统一代理多家 LLM）；管理侧有 API7 官方的 api7/apisix-mcp（已写入 APISIX 文档），本地智能体可通过 Admin API 查看和管理路由。

网关云原生MCP 官方

Kong Gateway

云原生 API 网关，靠插件做路由、鉴权、限流，也有官方 Kubernetes Ingress Controller 和管理界面 Kong Manager，对标 APISIX、Nginx。适合需要成熟插件生态，或打算用 Kong Konnect 托管控面的团队。AI 集成：官方 Kong/mcp-konnect 面向 Konnect 云控面；未查到面向自建开源 Kong 的官方本地 MCP。产品本身也提供 AI Gateway，可治理 LLM/MCP 流量并把 REST API 转成 MCP 工具。

网关插件MCP

Spring Cloud Gateway

跑在 Spring 生态里的 API 网关，官方文档写明分 Server（可独立部署或嵌入 Spring Boot 应用）和 Proxy Exchange 两种形态，且都支持 WebFlux 与 Web MVC。对标 Kong、APISIX 等独立网关，也是 Spring Cloud 里接替 Netflix Zuul 的方案，适合已经在用 Spring 的 Java 团队用代码或配置做路由、过滤和熔断。AI 集成：未查到针对 Spring Cloud Gateway 本身的官方 MCP 服务器。

JavaSpring

Traefik

Go 写的现代反向代理和负载均衡器，能监听 Docker、Kubernetes 等自动生成路由，单二进制部署并自带 Web UI。对标 Nginx Ingress、HAProxy，适合容器和 Kubernetes 入流量、不想手写大量路由配置的场景。AI 集成：Traefik Labs 于 2026-10-22 发布官方只读 Traefik MCP Server，可读取开源 Traefik Proxy v3 的运行配置并做校验，但需要具备许可的 Traefik Hub token 才能解锁。

网关K8sMCP 官方

Apache ShenYu

Java 原生 API 网关，用插件链做服务代理、协议转换和治理，自带 Admin 控制台，可代理 HTTP、Spring Cloud、WebSocket、Apache Dubbo、gRPC 等。对标 Spring Cloud Gateway、Kong，适合国内常见的 Dubbo / Spring Cloud 混合协议、又想用 Java 写插件的团队。AI 集成：官方内置 mcp-server 插件（SSE 和 Streamable HTTP），可用 @ShenyuMcpTool 把接口注册成 MCP 工具，见快速开始。

Java网关MCP 内置

Higress

基于 Istio 和 Envoy 的云原生 API 网关，可用 Go/Rust/JS 编写 Wasm 插件，并带开箱即用控制台；源于阿里，现为 CNCF Sandbox 项目。对标 Nginx Ingress、Kong，也常被当作 AI 网关，适合 Kubernetes 入口以及要把 LLM 和工具调用统一管理的场景。AI 集成：官方支持托管 MCP Server，可用 openapi-to-mcp 把 OpenAPI 转成远程 MCP，见文档；另有社区 cr7258/higress-ops-mcp-server 用于运维配置，未查到官方运维向 MCP。

网关CNCFMCP 内置

服务治理与服务网格 4

Sentinel

阿里巴巴开源的流量治理组件，做流控、隔离、熔断和系统自适应保护，自带控制台，并提供 Spring Cloud、Apache Dubbo、gRPC、Quarkus 等适配。对标 Netflix Hystrix、Resilience4j，适合秒杀、削峰和下游不稳定时的保护，在国内 Java 微服务里很常见。AI 集成：未查到。

限流熔断Java

Resilience4j

轻量级 Java 容错库，用装饰器给调用加上熔断、限流、重试和舱壁；当前主线 Resilience4j 3 需要 Java 21。对标已停止维护的 Netflix Hystrix，也是 Spring Cloud CircuitBreaker 的官方实现之一，适合不想引入 Sentinel 控制台、只在应用内做容错的 Spring 项目。AI 集成：未查到。

熔断JavaSpring

Istio

开源服务网格，几乎不用改业务代码就能做服务间流量管理、mTLS 认证和可观测性；数据面可用 Envoy sidecar，或 Ambient 模式下的轻量 ztunnel。对标 Linkerd 等网格，也补了“只在网关做治理、服务之间仍裸连”的缺口，适合已经上 Kubernetes、要给东西向流量统一加安全策略的团队。AI 集成：未查到官方 MCP；社区有 krutsko/istio-mcp-server。

服务网格K8s

Envoy

CNCF 托管的高性能边缘/中间/服务代理，常作为 Istio、Higress 等的数据面，也可以单独做 L7 反向代理和网关。对标 Nginx、HAProxy，适合需要动态配置、以及作为网格或网关数据面的场景。AI 集成：未查到用于管理 Envoy 本身的官方 MCP。
