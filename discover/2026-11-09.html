开源工具与中间件发现 · 第 3 期：消息队列与流处理

2026-11-09 周一 · 10 条 · 已读 0
🚀 最值得上手
1. Kafbat UI（原 Kafka UI）
Docker 一条命令连上 Kafka 就能看消息和消费积压，打开 MCP 后还能让本地智能体帮你查 topic，日常开发立刻用得上。
2. Debezium
CDC 是缓存、ES 同步和 Outbox 的常见解法，同事常提，搭一个 MySQL 到 Kafka 的 demo 就能看懂。
3. Redpanda
本地起一个兼容 Kafka 的单节点很轻，顺便理解为什么有团队用它替代 Kafka。

消息队列与事件流 7

Apache Kafka

分布式事件流平台，按分区顺序写日志，吞吐高、可回放，是日志采集、事件驱动和数据管道的事实标准，Spring 有 spring-kafka 直接用。对标 RabbitMQ、RocketMQ 等传统 MQ，适合大吞吐、需要多个消费方重复读取的场景。AI 集成：有官方 confluentinc/mcp-confluent，支持自建 Kafka，可列 topic、收发消息、查消费组积压。

事件流MCP 官方

Apache RocketMQ

阿里开源、Java 写的 Apache 顶级消息中间件，原生支持事务消息、延时消息、顺序消息和消息轨迹。对标 Kafka 和 RabbitMQ，在国内电商、金融等业务消息场景很常见，适合需要事务消息和严格可靠投递的 Java 业务系统。AI 集成：未查到官方 MCP；社区有 atengk/mcp-server-rocketmq 等小型实现。

Java业务消息

RabbitMQ

老牌 AMQP 消息代理，交换机加路由键的模型很灵活，支持优先级、死信、延迟（插件）等，新版本还有 Streams。对标 ActiveMQ，适合任务队列、复杂路由和中小吞吐的业务解耦，用 Spring AMQP 接入很顺手。AI 集成：有 AWS Amazon MQ 团队的 amazon-mq/mcp-server-rabbitmq，可管理队列、做健康检查。

AMQPMCP

Apache Pulsar

计算存储分离的消息与流平台，存储放在 BookKeeper，原生支持多租户、跨地域复制和分层存储。对标 Kafka，适合多团队共享集群、需要队列和流两种语义同时存在的场景。AI 集成：有 streamnative/streamnative-mcp-server，同时支持 Pulsar 和 Kafka。

存算分离MCP

NATS

Go 写的轻量消息系统，单个小二进制就能跑，延迟极低；JetStream 提供持久化、KV 和对象存储。对标 RabbitMQ、Redis Pub/Sub，适合微服务间通信、边缘和物联网这类要轻量的场景。AI 集成：未查到官方 MCP；社区有 sinadarbouy/mcp-nats。

轻量云原生

Redpanda

用 C++ 重写的 Kafka 协议兼容流平台，没有 ZooKeeper 和 JVM，单二进制部署。可直接替代 Kafka 集群，客户端不用改，适合想要更低延迟、更省机器和更简单运维的团队，本地开发也很方便。AI 集成：未查到。

Kafka 兼容

AutoMQ

把 Kafka 存储层改到 S3 对象存储上的“无盘 Kafka”，兼容 Kafka 协议，主打低成本和秒级扩缩容，README 里列了京东用它替换 Kafka 的案例。对标 Apache Kafka 和 Confluent，适合云上数据量大、存储成本高的场景。AI 集成：未查到。

Kafka 兼容S3

流处理与周边工具 3

Apache Flink

有状态流处理引擎，支持事件时间、窗口、精确一次和 Flink SQL，Java/Scala API。对标 Spark Streaming、Kafka Streams，适合实时报表、风控、实时 ETL 这类需要状态计算的场景。AI 集成：未查到官方 MCP；mcp-confluent 能管理 Confluent Cloud 上的 Flink SQL，社区有 Ashfaqbs/apache-flink-mcp-server。

流计算Java

Debezium

基于数据库日志的变更数据捕获（CDC）平台，把 MySQL、PostgreSQL、Oracle 等的增删改实时变成 Kafka 事件。对标 Canal、Maxwell，适合缓存同步、搜索索引同步、Outbox 模式和数据库迁移。AI 集成：未查到官方 MCP。

CDCJava

Kafbat UI（原 Kafka UI）

免费开源的 Kafka 管理界面，看 topic、消息、消费组积压、Schema Registry 和 Connect 都很方便，是 provectus/kafka-ui 的延续版。对标 Offset Explorer、Conduktor、AKHQ，开发和排查 Kafka 问题时几乎必备。AI 集成：内置 MCP 服务器，配置 mcp.enabled=true 后通过 /mcp/sse 接入（见官方说明）。
