mattpocock/skills

pingdotgg/t3code

开源的编程智能体控制台，一个界面驱动本机的 Claude Code、Codex、Cursor、Grok Build、OpenCode 等，还带 iOS/Android 远程 App；今日和本周 Trending，约 4.2 万星，TypeScript。

专为多个 AI 智能体并行干活设计的 Git worktree 管理 CLI，每个任务一个独立工作区、互不打架；今日 Trending，约 1 万星，Rust。

AI 应用与框架 4

paperclipai/paperclip

开源的多智能体团队编排应用，把一群 AI 智能体当成“公司”来分工和管理；今日 Trending，约 11 万星，TypeScript。

Agent编排

vercel-labs/agent-desktop

Vercel 出品的电脑操作 CLI，通过系统无障碍树读取并操作 macOS、Windows、Linux 桌面应用，返回 JSON 元素引用而不靠像素匹配；今日 Trending 第一，约 1 万星，Rust。

HeyGen 开源的“写 HTML 渲染成视频”框架，专为智能体生成视频设计；本周 Trending，约 7.8 万星。

阿里 AgentScope 的 Java 版，用来构建分布式、可长时间运行的生产级智能体，JDK 17+、已上 Maven Central；本周 Java Trending，约 6.2 千星。
