编程智能体与 Skills 6

addyosmani/agent-skills

Google 的 Addy Osmani 整理的生产级工程 Skills，把定义、规划、实现、测试、评审到上线的质量门槛交给 Claude Code、Codex、Cursor 等智能体按同一套习惯执行；本周 Trending，本周约增 3,900 星，2026 年 2 月创建，截至 11-16 约 11.8 万星，MIT。

Skill高星热门

affaan-m/ECC

面向编程智能体的 Harness 优化系统，提供 Skills、本能（instincts）、记忆、安全和“先调研再动手”的工作流，支持 Claude Code、Codex、OpenCode、Cursor；请只从官方仓库或 npm 包 ecc-universal 安装。2026 年 1 月创建，截至 11-16 约 30.4 万星，是历史期尚未收录、星数很高的项目，MIT。

Harness高星

backnotprop/plannotator

本地浏览器里的智能体审查工作台：给计划、决策和 diff 做批注，一键把反馈发回 Claude Code、Codex、OpenCode 等；今日和本周都在 Trending，今日约增 866 星、本周约增 1,700 星，截至 11-16 约 1.2 万星，Apache-2.0。

审查热门

Tencent/LoopForge

腾讯开源的自托管编程智能体工作流：主智能体在 Docker 沙箱里拉仓库、按角色分派，再把跑通的流程存成带人工审批关卡的 SOP；可编排 CodeBuddy、Codex、Claude Code 等。2026 年 7 月创建，今日 Trending，今日约增 423 星，截至 11-16 约 1,700 星。

编排热门

google-labs-code/stitch-skills

Google Labs 的 Stitch 设计 Skills，遵循 Agent Skills 开放标准，可与 Stitch MCP 以及 Claude Code、Cursor、Gemini CLI 等一起用；今日 Trending，截至 11-16 约 9,400 星，Apache-2.0。

Skill官方热门

GoogleChrome/modern-web-guidance-src

Chrome 团队《Modern Web Guidance》的源码库，把现行 Web 最佳实践和浏览器兼容数据做成 Skills，避免智能体写出过时写法；今日 Trending，今日约增 1,200 星，2026 年 1 月创建，截至 11-16 约 7,300 星，Apache-2.0。

Skill官方热门

AI 应用与框架 4

meta/astryx

Meta 开源、面向人和智能体的设计系统，在公司内部用了约八年，基于 React 19 和 StyleX，目前仍是 Beta。本周 Trending 第 1，本周约增 13,500 星，2026 年 1 月开源，截至 11-16 约 2.9 万星，MIT。

设计系统热门

ag-ui-protocol/ag-ui

把智能体接到前端应用的开放事件协议 AG-UI，可用 npx create-ag-ui-app 起一个示例；今日 Trending 第 2，截至 11-16 约 1.8 万星，TypeScript、MIT。

协议热门

dream-num/univer

开源的 AI 办公 SDK，把表格、文档、幻灯片的编辑、计算、协作和文件处理嵌进自己的产品，同时给人和智能体用；今日 Trending 第 1，今日约增 988 星，截至 11-16 约 2.6 万星，Apache-2.0。

办公SDK热门

Leonxlnx/taste-skill

给编程智能体补“品味”的 Skill：用艺术方向、参考图和浏览器检查，避免做出千篇一律的 AI 风页面；本月 Trending，本月约增 19,500 星，2026 年 2 月创建，截至 11-16 约 11.6 万星，历史期未收录，MIT。

Skill设计高星

开发者工具与基础设施 2

alibaba/open-code-review

阿里巴巴内部用了两年后开源的 AI 代码审查 CLI：确定性规则加上大模型智能体，给出精确到行的评论，内置空指针、线程安全、XSS、SQL 注入等规则，兼容 OpenAI 和 Anthropic 接口。今日 Trending，今日约增 691 星，2026 年 5 月开源，截至 11-16 约 5.2 万星，Go、Apache-2.0。

代码审查Java热门

ChromeDevTools/chrome-devtools-mcp

Chrome 官方把 DevTools 做成 MCP 服务器和 CLI，让编程智能体控制并检查正在运行的 Chrome，做自动化、调试和性能分析；今日 Trending，今日约增 717 星，截至 11-16 约 5.7 万星，Apache-2.0。
