编程智能体与 Skills 6

stablyai/orca

开源的多编程智能体编排应用，Claude Code、Codex 等智能体并行干活，每个都在自己的 git worktree 里，用你自己的订阅；桌面、手机和远程运行时都能用，MIT。2026 年 3 月创建，截至 11-09 约 11.9 万星。

Coding Agent编排热门

deepseek-ai/deepseek-harness

DeepSeek 官方开源的智能体框架 dsh，“万物皆插件”架构，npx @deepseek-ai/dsh web 即可在本地起 Web UI；仍是开发者预览、会有不兼容变更。8 月创建，截至 11-09 约 27.7 万星，是近三个月新建仓库里星数最高的。

AgentDeepSeek高星

morluto/rea

“逆向一切”：一个 MCP 让智能体从应用行为一路分析到原生二进制，弄懂别人某个功能是怎么做的；本月 GitHub Trending，截至 11-09 约 44.4 万星，TypeScript、MIT。

MCP逆向高星

anthropics/skills

Anthropic 官方的 Agent Skills 公共仓库，学写 Skill 的标准范例；今日和本周 Trending，截至 11-09 约 19 万星。

Skill官方

Nutlope/hallmark

给 Claude Code、Cursor、Codex 用的“反 AI 味”设计 Skill，让智能体做出的界面不那么千篇一律；本周和本月 Trending，截至 11-09 约 5.1 万星。

Skill设计

yetone/magpie

菜单栏里统一管理各编程智能体用哪个模型：Claude Code 跑 Kimi、Codex 跑 DeepSeek，一个本地网关服务所有智能体，额度用完自动切下一个账号；9 月创建，截至 11-09 约 3.2 万星，Go。

Coding Agent模型网关Go

AI 应用与框架 3

vercel-labs/agent-browser

Vercel 出品、给 AI 智能体用的浏览器自动化 CLI；今日和本周 Trending，截至 11-09 约 4.8 万星，Rust。

浏览器CLIRust

google/elephant-goldfish-model

谷歌开源的设计评审插件：“大象”带着项目上下文写规格文档，“金鱼”评审员不看之前对话、只看草稿和源材料，帮你找出没说清的假设；支持 Claude Code、Codex 等。9 月创建，截至 11-09 约 1.5 万星。

Skill设计评审

deepseek-ai/DeepInfer

DeepSeek 开源其生产服务用的大规模推理框架，支持 DeepSeek-V4.1-Flash，含 EP 并行、批不变推理、确定性采样和结构化输出；10 月中创建，截至 11-09 约 2.6 万星。

推理DeepSeek

开发者工具与基础设施 3

github/spec-kit

GitHub 官方的规格驱动开发（SDD）工具包，先写规格再让智能体按规格实现；本周 Trending，截至 11-09 约 14.9 万星。

SDD官方高星

firecrawl/anydoc

把 Word、PPT、Excel、PDF、EPUB 等转成干净的 Markdown，方便喂给 RAG 和智能体，Rust 实现并带 Node.js、Python 绑定；8 月创建，截至 11-09 约 2.3 万星。

文档转换RAGRust

floci-io/floci-az

上期 Floci（本地 AWS 模拟器）的 Azure 版，Java + Quarkus 写的，docker compose up 就能在本地模拟 Blob、Service Bus、Key Vault、Cosmos DB 等，无需账号；本周 Java Trending，截至 11-09 约 900 星。
