编程智能体与 Skills 4

JetBrains/thinkrail

JetBrains 出品的轻量 IDE，围绕 pi 编程智能体做 vibe coding，界面会按你的工作习惯自我定制；今日 Trending，约 6.1 千星，TypeScript。

Coding AgentIDE热门

obra/superpowers

智能体 Skills 框架加一整套软件开发方法论（先设计、再写测试、再实现），让编程智能体按工程流程干活；今日与本周 Trending 均上榜，约 30.9 万星。

Skill方法论热门

thedotmack/claude-mem

给编程智能体加跨会话的持久记忆：记录会话中的操作、用 AI 压缩，再把相关上下文注入后续会话，支持 Claude Code、Codex、Gemini、Copilot、OpenCode 等；今日 Trending，约 10.5 万星。

记忆Claude Code热门

pbakaus/impeccable

给编程智能体的一套设计词汇和命令（打磨、加强、评审、审计），在上线前拦住“AI 味”的粗糙界面；今日与本周 Trending，约 9.6 万星，Rust。

Skill前端设计热门

AI 应用与框架 3

CopilotKit/OpenBot

开源“AI 同事”平台：每个智能体有自己的浏览器、文件和工具，每个动作先审批、后留痕，可接任意 AG-UI 智能体；今日 Trending，约 8.2 千星。

Agent可审计热门

anthropics/knowledge-work-plugins

Anthropic 官方的知识工作插件合集，主要用于 Claude Cowork，可参考它的插件和 Skill 写法；本周 Trending，约 3.4 万星。

插件官方热门

HKUDS/DeepTutor

港大数据智能实验室的个性化 AI 导师系统，主打长期学习陪伴，可参考其多智能体和 RAG 设计；今日 Trending，约 5.0 万星，Python。

AI 应用教育Python

Java 与后端基础设施 2

opendataloader-project/opendataloader-pdf

Java 写的 PDF 解析器，把 PDF 转成适合 AI/RAG 使用的结构化数据，也能做 PDF 无障碍处理；本周 Java Trending，约 3.0 万星。

JavaRAGPDF

DependencyTrack/dependency-track

OWASP 的软件成分分析平台，导入 SBOM 后持续追踪依赖漏洞和许可证风险，适合 Maven 项目做供应链安全；本周 Java Trending，约 4.4 千星。
