编程智能体与 Skills 5

DietrichGebert/ponytail

把“懒惰的高级开发”装进编程智能体：先看仓库里已有的能力，只写任务真正需要的代码，并用 /ponytail-review 按线上故障的思路做审查；支持 Claude Code、Codex、Cursor 等约 20 种智能体。2026 年 6 月创建，截至 11-23 约 19.7 万星，是历史期尚未收录的高星项目，MIT。

Skill高星

mvanhorn/last30days-skill

给编程智能体用的调研 Skill：并行检索 Reddit、Hacker News、X、YouTube、Polymarket 和网页，按赞数、热度和真实资金盘口综合出有依据的摘要；支持 Claude Code、Codex、Cursor、Gemini CLI 等。今日和本周都在 Trending，本周约增 4,700 星，2026 年 1 月创建，截至 11-23 约 7.3 万星，MIT。

Skill热门高星

cathrynlavery/diagram-design

给 Claude Code、Codex、Cursor 等用的制图 Skill：按要求画出约 51 种架构图和示意图，输出自包含的 HTML + SVG，避免千篇一律的 Mermaid 风格。今日 Trending，今日约增 518 星，2026 年 4 月创建，截至 11-23 约 7.0 万星，是历史期尚未收录的高星项目，MIT。

Skill热门高星

cursor/plugins

Cursor 官方插件与规范仓库，收录持续学习、深度分支审查（Thermos）、Ralph Loop、PR 审查画布等官方插件，也是第三方插件的清单入口。今日 Trending，今日约增 294 星，2026 年 1 月创建，截至 11-23 约 1.9 万星，MIT。

官方热门

janestreet/agent_skills

Jane Street 从内部仓库公开的 Agent Skills，目前主要是 socratic-tutor：用苏格拉底问答当私人导师，带诊断、0–5 级技能图、间隔复习和结业评估。2026 年 11 月 3 日创建，约三周内达到约 1.1 万星，MIT。

Skill高星

AI 应用与框架 4

HKUDS/CLI-Anything

港大数据智能实验室开源的框架：给 GIMP、Blender、LibreOffice 等 GUI 软件自动生成带状态的命令行接口，让 Cursor、Claude Code 等智能体能用 JSON 输出操作这些软件。今日 Trending，今日约增 699 星，2026 年 3 月创建，截至 11-23 约 6.3 万星，Apache-2.0。

热门高星

NousResearch/hermes-agent

Nous Research 的自改进智能体：能从经验里生成并改进 Skills，跨会话检索记忆，并在 Telegram、Discord、Slack 和终端里用同一套网关对话；模型可换，也可跑在 VPS 或无服务器环境。2025 年 7 月创建，截至 11-23 约 26.5 万星，是历史期尚未收录的高星项目，MIT。

智能体高星

milind-soni/OpenMausBot

开源的桌面聊天应用，把 Claude、Codex 等本地智能体做成侧边栏里的“联系人”，每个智能体有自己的人格、模型和云端电脑。本月 Trending，本月约增 2.1 万星，2026 年 8 月创建，截至 11-23 约 2.7 万星，Apache-2.0。

热门

browser-use/browser-use

给 AI 智能体用的开源 Python 浏览器自动化库，可驱动真实浏览器完成点击、填写和抓取，并带 MCP 与云端浏览器选项。2024 年 10 月创建，截至 11-23 约 12.2 万星，是历史期尚未收录的高星项目，MIT。

浏览器高星

开发者工具与基础设施 3

Tracer-Cloud/opensre

面向 CI/CD 可靠性的开源智能体：读取失败的流水线、追踪根因，并提交一份供你审查的修复；可自托管、使用自己的模型。目前仍是 Public Alpha。今日 Trending，今日约增 399 星，2026 年 1 月创建，截至 11-23 约 1.4 万星，Apache-2.0。

CI/CD热门

firecrawl/firecrawl

给智能体用的知识基础设施：把网页转成干净 Markdown，并可通过同一 API 检索 550 多家数据源；可在本机以单个二进制加 MCP 运行，也可云端或自托管。今日 Trending，今日约增 915 星，截至 11-23 约 20.7 万星，是历史期尚未收录的高星项目，AGPL-3.0。

热门高星

microsoft/copilot-sdk

微软把 Copilot 智能体运行时做成可编程 SDK，支持 Python、TypeScript、Go、.NET、Java 和 Rust，Java 版已上 Maven Central（com.microsoft:copilot-sdk），可在自己的应用里调用规划、工具和改文件等能力。Java 今日 Trending，2026 年 1 月创建，截至 11-23 约 1.1 万星，MIT。
