编程智能体与 Skills 4

anomalyco/opencode

开源的终端编程智能体，可接多家模型，是闭源 Coding Agent 的开源替代；本周 GitHub Trending 上榜，约 22.2 万星，TypeScript。

Coding Agent热门TypeScript

wshobson/agents

面向 Claude Code、Codex、Cursor、OpenCode、Copilot 等多种工具的智能体插件市场，可直接挑选现成的子智能体和工作流；本周 Trending，约 4.2 万星。

Agent插件热门

cloudflare/security-audit-skill

Cloudflare 出品的编程智能体 Skill，按多阶段做安全审计，输出经独立验证、机器可读的问题清单，适合接入代码评审；本周 Trending，约 4.9 万星。

Skill安全热门

Graphify-Labs/graphify

把整个代码库连同文档、SQL 表结构、配置和 PDF 转成可查询的知识图谱，方便 AI 理解大型老项目；本周 Trending，约 13.7 万星，Python。

知识图谱代码理解热门

Agent 框架与 MCP 4

langchain-ai/langgraph

LangChain 团队的有状态智能体编排框架，用图来描述多步流程，支持持久化与人工介入；约 4.4 万星，Python。

Agent 框架Python

pydantic/pydantic-ai

Pydantic 团队的类型安全 Agent 框架，支持多家模型、结构化输出和工具调用，写法接近 FastAPI；约 2.1 万星。

Agent 框架Python

modelcontextprotocol/servers

MCP 官方的参考服务器合集（文件系统、Git、抓取等），学 MCP 协议和自己写 MCP Server 的最佳起点；约 9.2 万星。

MCP参考实现

microsoft/playwright-mcp

微软的 Playwright MCP 服务器，让 AI 通过结构化页面快照操控浏览器，可用于端到端测试和网页自动化；约 3.9 万星。

MCP测试浏览器

本地大模型与 RAG 3

ollama/ollama

一条命令在本地跑 Kimi、GLM、DeepSeek、Qwen、Gemma 等开源模型，并提供 OpenAI 兼容接口，本地开发调试首选；约 18.5 万星，Go。

本地 LLMGo

ggml-org/llama.cpp

纯 C/C++ 的大模型推理引擎，支持量化，在笔记本和 Apple Silicon 上也能跑，是众多本地工具的底层；约 13.3 万星。

推理C++

infiniflow/ragflow

开源 RAG 引擎，擅长深度解析复杂文档并结合 Agent 能力，适合搭企业知识库问答；约 9.3 万星。

RAG知识库

可观测性与开发工具 3

langfuse/langfuse

开源的 LLM 应用可观测与评测平台：链路追踪、评测、提示词管理，可自托管；约 3.7 万星，TypeScript。

可观测性评测LLMOps

astral-sh/uv

Rust 写的极速 Python 包和项目管理器，一个工具替代 pip、venv、pyenv 等，跑 AI 脚本很省事；约 9.1 万星。

开发工具PythonRust

jesseduffield/lazygit

终端里的 Git 图形界面，暂存、变基、挑拣提交都靠快捷键，日常提效明显；约 8.3 万星，Go。
